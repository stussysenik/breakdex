2.  **Psychology of Action & Trust (Meaning):** Colors should do a job. We'll use a stable, trustworthy blue as our base and an energetic, action-oriented color to signify progress and forward momentum.
3.  **Minimalist & Functional (Simplicity):** The loading screen is temporary. Its design should be clean and unobtrusive, conveying status without distracting from the primary task.

#### **Step 1: Update the Design System**

To ensure consistency and scalability, the new colors should be added as semantic tokens to the app's design system.

  * **Task:** Define new semantic colors in the `DesignSystem.swift` file. This is crucial for maintaining a single source of truth for your app's theme.
  * **File:** `Utils/DesignSystem.swift`
  * **Implementation:** Add the following to your `DesignSystem.Colors` enum.
    ```swift
    // Inside DesignSystem.Colors enum
    static let loadingOverlayBackground = Color(hex: "0f62fe") // Blue 60
    static let progressIndicator = Color(hex: "3ddbd9")       // Teal 30
    static let textPrimary = Color(hex: "ffffff")             // White 0
    static let textSecondary = Color(hex: "c1c7cd")          // Cool Gray 30
    ```
