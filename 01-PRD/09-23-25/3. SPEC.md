### **Spec-Kit: Trimmer Precision and State-Driven Boundary Enforcement**

**Project:** `feature/trimmer-precision-refactor`

**Objective:** Refactor the video trimming interface to provide a "digital caliper-like" user experience. This involves replacing interpolated animations with precise, millisecond-accurate timecode displays, and implementing a hard, state-driven 3-second minimum duration boundary with clear user feedback.

**Key Principles:**

  * **Precision (WYSIWYG):** All displayed time values must reflect the exact, frame-snapped `CMTime` values from the `TrimmerViewModel`. Floating-point inaccuracies and animation artifacts must be eliminated.
  * **State-Driven UI:** All UI feedback, including warnings and alerts, must be driven by state variables published from the `TrimmerViewModel`. The view layer will contain no local state logic for these features.
  * **Intentional Feedback:** User interactions at boundaries should provide clear, multi-sensory feedback: a hard stop in movement, a haptic bump, a one-time alert, and a persistent visual warning.

**Affected Components:**

  * `TrimmerViewModel.swift`: Core state management and validation logic.
  * `FeatureRichTrimmerView.swift`: Main UI container for the trimmer and alert presentation.
  * `ReactiveTimeCodeComponent.swift`: The timecode display UI component.
  * `Utils/TimecodeFormatter.swift`: **New file** to centralize time formatting logic.

#### **Phase 1: Establish a Single Source of Truth for Time Formatting**

  * **Task 1.1: Create Centralized `TimecodeFormatter` Utility**
      * [ ] **Action:** Create a new Swift file named `TimecodeFormatter.swift` inside the `Utils/` directory.
      * [ ] **Contents:** Populate the file with the following `public enum` to provide a static, globally accessible formatting function. This approach uses `CMTimeConvertScale` to ensure millisecond precision and avoid floating-point rounding errors.
        ```swift
        import Foundation
        import CoreMedia

        public enum TimecodeFormatter {
            public static func format(time: CMTime) -> String {
                guard time.isValid && !time.isIndefinite else {
                    return "00:00.000"
                }
                let totalMilliseconds = CMTimeConvertScale(time, timescale: 1000, method: .roundHalfAwayFromZero).value
                let seconds = totalMilliseconds / 1000
                let minutes = seconds / 60
                let displaySeconds = seconds % 60
                let displayMilliseconds = totalMilliseconds % 1000
                return String(format: "%02d:%02d.%03d", minutes, displaySeconds, displayMilliseconds)
            }
        }
        ```
      * **Acceptance Criteria:** The file exists and compiles successfully.

        ```swift
        public func validateWithHandleState(_ proposedTime: CMTime, for handle: TrimmerHandleType) -> ValidationResult {
            var validatedTime = max(.zero, min(proposedTime, videoDuration))
            var didHitLimit = false
            var boundaryType = ""
            var constraintSeverity = ConstraintSeverity.none

            switch handle {
            case .start:
                let limit = endTime - minimumDuration
                if validatedTime > limit {
                    validatedTime = limit
                    didHitLimit = true
                    boundaryType = "minimum_duration_start"
                    constraintSeverity = .hard
                }
            case .end:
                let limit = startTime + minimumDuration
                if validatedTime < limit {
                    validatedTime = limit
                    didHitLimit = true
                    boundaryType = "minimum_duration_end"
                    constraintSeverity = .hard
                }
            }
            return ValidationResult(
                validatedTime: validatedTime,
                didHitLimit: didHitLimit,
                boundaryType: boundaryType,
                constraintSeverity: constraintSeverity,
                minimumDuration: minimumDuration
            )
        }
        ```

        public func proposeTime(_ proposedTime: CMTime, for handle: TrimmerHandleType) {
            let snappedTime = snapToFrame(proposedTime)
            let validation = validateWithHandleState(snappedTime, for: handle)
            let validatedTime = validation.validatedTime

            switch handle {
            case .start:
                if startTime != validatedTime { startTime = validatedTime }
            case .end:
                if endTime != validatedTime { endTime = validatedTime }
            }
            self.pendingPreviewTime = validatedTime
            
            let currentDuration = self.endTime - self.startTime
            showMinimumDurationWarning = currentDuration.seconds <= minimumDuration.seconds

            if validation.isAtBoundary && !hasShownAlertThisDragSession {
                showMinDurationAlert = true
                hasShownAlertThisDragSession = true
                triggerBoundaryHaptic()
            }
            
            if !showMinimumDurationWarning {
                hasShownAlertThisDragSession = false
            }
        }
