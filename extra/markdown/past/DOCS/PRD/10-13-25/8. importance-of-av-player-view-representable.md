# AVPlayerViewRepresentable

⏺ AVPlayerViewRepresentable is a bridge between Apple's AVPlayer (from AVKit) and SwiftUI.
  SwiftUI can't directly use UIKit components like AVPlayerViewController, so this wrapper
  converts the UIKit video player into something SwiftUI can display.

  Think of it like a translator - it takes the native iOS video player (which is UIKit-based) and
   wraps it in a way that SwiftUI understands and can render in the view hierarchy. This is a
  common pattern when you need to use existing UIKit components in a SwiftUI app.
