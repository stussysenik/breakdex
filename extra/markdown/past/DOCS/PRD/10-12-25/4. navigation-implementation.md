The most robust minimal approach for a complex SwiftUI app like this is a NavigationStack per tab with a tiny Router object that owns a NavigationPath and a small Route enum, injected at the root and per feature as needed for programmatic pushes/pops and deep linking. For flows that are multi-step and conditional (e.g., AddMove), prefer a lightweight feature-level coordinator using the same NavigationPath rather than a global state machine; reserve GKStateMachine for truly stateful wizards where legal transitions must be enforced. ### ELI19 (6 sentences)
Think of navigation as a stack of pages, and give each tab its own stack so pages don’t step on each other. [3][1] Put the “map” for each stack in a small Router that holds a path and offers push/pop methods using a Route enum for type-safe destinations. [2][4] Keep this Router at the top of the view tree (and per feature when needed) so views can request navigation without hardcoding links. [2][1] For a multi-step flow like picking, trimming, and naming a video, wrap those steps in a mini coordinator that controls just that feature’s path and any sheets/covers. [1][5] Only bring in a strict state machine if the flow has complex rules (e.g., cannot trim before asset is fully loaded) and needs compile-time transition guarantees. [6][7] This keeps everyday navigation simple while leaving room to scale for deep links, tabs, and background work like video loading and progress reporting. [1][8]

### Wiki-flavored knowledge
NavigationStack: A SwiftUI container that manages a push/pop stack of destinations and replaces NavigationView for modern, type-safe navigation. [3][4]
NavigationPath: A data-driven history for a NavigationStack that enables programmatic navigation by appending or removing typed Route values. [2][3]
Router: An observable object that centralizes navigation intent (push/pop/replace) by owning a NavigationPath and exposing helpers to views and view models. [2][9]
Coordinator: A pattern that decouples flow control from views by handling route decisions, stack mutations, and presentation (push/sheet/fullScreenCover) per feature or section. [5][10]
GKStateMachine: A GameplayKit utility to model states and valid transitions for complex flows where navigation depends on strict rules. [6][7]
Deep linking: Routing that reconstructs the correct tab and stack state from an external URL or notification by seeding the appropriate NavigationPath. [8]

### Examples
- Example 1 — Per-tab Router with Route enum  
Create Route and a Router for the Arsenal tab, then bind it to NavigationStack in MainView while leaving other tabs independent. [1][2]
```swift
enum ArsenalRoute: Hashable { case moveList, moveDetail(id: UUID), comboList }

@Observable final class ArsenalRouter {
    var path = NavigationPath()
    func push(_ r: ArsenalRoute) { path.append(r) }
    func pop() { if !path.isEmpty { path.removeLast() } }
}

struct ArsenalTab: View {
    @State private var router = ArsenalRouter()
    var body: some View {
        NavigationStack(path: $router.path) {
            MoveListView()
                .navigationDestination(for: ArsenalRoute.self) { route in
                    switch route {
                    case .moveList: MoveListView()
                    case .moveDetail(let id): MoveDetailView(moveID: id)
                    case .comboList: ComboListView()
                    }
                }
        }
        .environment(router)
    }
}
```
This keeps Arsenal navigation isolated, plays nicely with the existing Tab container, and avoids cross-tab coupling. [1][3]

- Example 2 — Mini coordinator for AddMove flow  
Model the picker → trim → name flow inside a feature-level coordinator that commands the path and presents sheets while delegating work to VideoLoader/VideoTrimmer and reporting via UnifiedProgressEngine. [1][5]
```swift
enum AddMoveRoute: Hashable { case pick, trim(assetID: String), name(assetID: String) }

@Observable final class AddMoveCoordinator {
    var path = NavigationPath()
    func start() { path = NavigationPath(); path.append(AddMoveRoute.pick) }
    func didPick(_ id: String) { path.append(.trim(assetID: id)) }
    func didTrim(_ id: String) { path.append(.name(assetID: id)) }
    func cancel() { path = NavigationPath() }
}
```
This isolates multi-step logic, integrates with existing services (VideoLoader, VideoProcessor), and remains testable without imposing a global state machine. [1][5]

- Example 3 — Deep link to Combo detail  
On URL open, set TabState to the Combo/Create tab, then seed that tab’s Router path with [.comboList, .comboDetail(comboID)], reconstructing the stack deterministically. [1][8]
```swift
func handle(url: URL, app: AppContainer) {
    guard let comboID = parseComboID(url) else { return }
    app.unifiedState.tab = .createCombo
    app.comboRouter.path = NavigationPath()
    app.comboRouter.path.append(ComboRoute.list)
    app.comboRouter.path.append(ComboRoute.detail(id: comboID))
}
```
This respects the existing feature structure and central state while providing reliable external navigation behavior. [1][8]
