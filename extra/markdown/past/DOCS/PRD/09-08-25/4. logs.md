## 🚨 Current Issues

### 1. **Video Display Failure**
- **Symptom**: Videos appear completely black/pitch black
- **Location**: Both NameMoveView preview and saved video playback
- **Timing**: Occurs after rotation effect is applied

### 2. **Rotation Effect Application**
- **Current**: Applied to ZStack container containing VideoPlayer
- **Previous**: Applied directly to VideoPlayer (caused black screen)
- **Issue**: Container-level rotation still breaks video rendering

### 3. **Debugging Evidence**
From logs, we can see:
- ✅ Rotation data saves correctly (`rotationQuarterTurns` values persist)
- ✅ Video export succeeds (files are created)
- ✅ AVPlayer setup works (no player errors)
- ❌ Video rendering fails (black display)

## 🔍 Potential Root Causes

### 1. **SwiftUI VideoPlayer Limitations**
SwiftUI's `VideoPlayer` may not properly handle transform effects like rotation, even when applied to containers.

### 2. **AVPlayer Layer Issues**
The rotation might interfere with the underlying `AVPlayerLayer` rendering pipeline.

### 3. **ZStack Composition Issues**
The ZStack with rotation might be causing composition problems with the VideoPlayer.

### 4. **Hardware Acceleration Conflicts**
Rotation transforms might conflict with video hardware acceleration.

## 🛠️ Potential Solutions to Investigate

### Solution 1: Custom Video Layer
```swift
struct RotatedVideoPlayer: UIViewRepresentable {
    let player: AVPlayer
    let rotation: Int
    
    func makeUIView(context: Context) -> UIView {
        let view = UIView()
        let playerLayer = AVPlayerLayer(player: player)
        
        // Apply rotation at AVPlayerLayer level
        playerLayer.transform = CATransform3DMakeRotation(
            CGFloat(rotation) * .pi / 2, 0, 0, 1
        )
        
        view.layer.addSublayer(playerLayer)
        return view
    }
}
```

### Solution 2: Pre-rotated Video Assets
Instead of runtime rotation, pre-rotate videos during export and store multiple versions.

### Solution 3: Alternative Video Display
Use `AVPlayerViewController` with custom rotation handling instead of SwiftUI's VideoPlayer.
