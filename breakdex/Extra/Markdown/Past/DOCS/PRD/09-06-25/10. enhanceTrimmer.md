### **Spec Update: v1.4—Precision & Tactile Feel**

| **Feature Name** | Ultra-Precise Video Trimmer |
| :--- | :--- |
| **Parent Spec** | v1.3 |
| **Status** | Iteration Scoped for Implementation |
| **Author** | Senior Principal Architect & Design Engineer |
| **Change** | Overhaul of the range slider's interaction model for maximum precision and tactile satisfaction, coupled with a refined visual design for the action bar. |

#### **1. Specify (Refinement)**

This iteration is singularly focused on elevating the trimming interaction from "functional" to "delightful and precise." The existing slider is not providing the frame-level accuracy and satisfying feedback users expect from a high-quality media tool.

*   **Case Study 1: The "Lift-Off" Problem**
    *   **Problem:** Users report that when they lift their finger after dragging a handle, the value sometimes "jumps," undoing their careful selection. This is a common issue with standard sliders where the touch-up event is imprecise [1].
    *   **Goal:** Implement a drag model that completely eliminates lift-off value changes, ensuring the final selected frame is exactly what the user intended.
*   **Case Study 2: The "Coarse Scrub" Problem**
    *   **Problem:** Dragging a handle across a long video's timeline makes it impossible to select a single frame. The physical distance of the slider is too small for the temporal length.
    *   **Goal:** Introduce a velocity-based precision mode that feels natural and intuitive, allowing for both fast and slow scrubbing within a single, continuous gesture [2][3].
*   **Case Study 3: The "Aesthetic Disconnect" Problem**
    *   **Problem:** The grey action buttons at the bottom feel disconnected from the app's overall design, appearing like generic, unstyled controls.
    *   **Goal:** Redesign the bottom bar to use a palette that complements a dark, media-focused environment, creating a more professional and immersive feel [4].

#### **2. Experience (Refined)**

*   **Velocity-Based Precision Scrubbing (New):** This is the core of the new interaction model.
    *   **Fast Drag:** When the user swipes a handle quickly, the timeline scrubs at a normal 1:1 ratio. This is for coarse, rapid adjustments.
    *   **Slow Drag:** As the user's drag velocity decreases below a certain threshold, the scrubbing ratio changes dynamically. Moving the finger 10 points might now only move the handle by 1 point on the timeline. This "gearing down" allows for frame-by-frame precision without a separate mode or gesture [2]. The finger can even be dragged vertically away from the slider to increase precision further, a technique used in Apple's own Photos app [5][6].
*   **Haptic Engine Integration (Refined):**
    *   **Selection:** A distinct "tap" (`.light` or `.soft`) is felt when a handle is first "grabbed" and again when released [7].
    *   **Scrubbing:** As the handle moves, subtle ticks are felt. In **fast drag** mode, these are infrequent. In **slow drag** mode, the haptics become more granular, providing a "click" for each individual frame the handle passes over, creating a satisfying "detent" feel [7].
*   **Visual Palette (Refined):**
    *   **Action Bar:** The grey background for the buttons is eliminated. Instead, the buttons will sit on the true-black background of the view.
        *   The primary action (`Save Trim`) will use a filled style with `systemBlue` background and white text.
        *   Secondary actions (`Back`, `[Contextual]`) will use a `prominent` or `borderless` button style, tinted with a subtle off-white or light grey color to differentiate them without introducing a jarring background color [4]. This enhances the "pro-app" aesthetic.

#### **3. Functional Requirements (Updated)**

*   **FR15 (New): Velocity-Sensitive Drag:** The `DragGesture` must track not only the translation but also the velocity of the gesture. When the drag velocity is low, the change in the handle's value must be scaled down, creating a high-precision mode.
*   **FR16 (New): Vertical Precision Axis:** If a user drags their finger vertically away from the slider's track while still engaged in a horizontal drag, the precision ratio must increase further, allowing for ultra-fine adjustments.
*   **FR17 (New): Frame-Detent Haptics:** A haptic generator must be triggered to produce a sharp, discrete "tick" for every single frame the slider's value changes during slow-drag mode.
*   **FR18 (New): "Pro" Action Bar Style:** The bottom action bar must be redesigned to remove the grey background, using button styles that work directly on a black canvas (`.borderedProminent` for the primary action, `.borderless` for secondary).

#### **4. Tasks (Updated)**

*   **Task 1: Implement Velocity-Tracking Drag Gesture:**
    *   Create a custom gesture or state-based logic that monitors the drag translation over time to calculate velocity.
    *   Define a threshold to switch between "fast" and "slow" scrubbing modes.
*   **Task 2: Develop Dynamic Scaling Logic:**
    *   In the gesture's update handler, apply a scaling factor to the drag's translation based on the current mode (fast or slow) and the vertical distance from the slider track.
*   **Task 3: Integrate Granular Haptics:**
    *   Create a `UISelectionFeedbackGenerator` or `UIImpactFeedbackGenerator`.
    *   In the logic that updates the handle's value, check if the value has crossed a frame boundary. If so, trigger the haptic feedback. Ensure this is done precisely once per frame change.
*   **Task 4: Redesign the Bottom Action Bar:**
    *   Remove the background container from the button `HStack`.
    *   Apply appropriate SwiftUI button styles: `.borderedProminent` with a `.tint(.blue)` for "Save Trim," and a `.buttonStyle(.borderless)` with a `.tint(.gray)` for the other buttons.

#### **5. Acceptance Criteria**

*   **AC1:** A user can scrub through a 10-minute video and easily select a single, specific frame by slowing down their drag motion.
*   **AC2:** Haptic feedback provides a tangible "click" for each frame passed in precision mode, confirming the user's selection.
*   **AC3:** Dragging a finger down and away from the slider noticeably increases the precision of the scrub.
*   **AC4:** The bottom buttons no longer have a grey background, and the primary "Save" button is visually distinct from the secondary actions, all on a pure black background.
