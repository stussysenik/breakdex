## Spec-Kit: A First-Principles Trimmer Correction

This spec re-establishes the fundamental rules for the trimmer's coordinate system to guarantee a valid state and a visually perfect representation.

### Diagnosis: The "Missing Point"

The system must operate on the principle that the selected range exists **between the inner edges of the two handles**. All calculations for the UI and the trimming logic must be derived from this principle.

### First Principles

1.  **Principle of Edges:** The selected time range begins at the **trailing edge** of the start handle and concludes at the **leading edge** of the end handle.
2.  **Principle of Visual Truth:** The blue selection bar must be drawn to perfectly fill the space defined by the Principle of Edges. It should not extend underneath the handles.
3.  **Principle of Invariant State:** The core logic must make it physically impossible for the handles to overlap. This guarantees the invariant that `startTime` is *always* less than `endTime`.

### Requirements

  - **R1: Edge-Based Selection Bar:** The blue `Capsule` view must be refactored to be offset and sized based on the handle's edges, not its center.
  - **R2: Edge-Based Clamping:** The drag gesture logic must be rewritten to enforce a gap between the **outer edges** of the handles, preventing any visual overlap.
  - **R3: Failsafe State Logic:** The `TrimmerViewModel` itself, as the source of truth, should ideally contain failsafe logic to prevent an invalid range from ever being set.

private func makeDragGesture(isStartHandle: Bool, totalWidth: CGFloat) -> some Gesture {
    DragGesture()
        .onChanged { dragValue in
            // ... (on drag start logic remains the same) ...
            
            var transaction = Transaction()
            transaction.disablesAnimations = true
            
            withTransaction(transaction) {
                if isStartHandle {
                    let newPosition = startHandlePosition(in: totalWidth) + dragValue.translation.width
                    
                    // The max position is the end handle's center MINUS a full handle width and the minimum gap.
                    // This ensures their outer edges cannot cross.
                    let minimumPixelGap = totalWidth * (viewModel.oneFrameDuration / viewModel.videoDuration)
                    let maxPosition = endHandlePosition(in: totalWidth) - handleWidth - minimumPixelGap
                    
                    let clampedPosition = max(0, min(newPosition, maxPosition))
                    
                    // ... (rest of the logic is the same)
                    let proposedTime = positionToTime(clampedPosition, totalWidth: totalWidth)
                    let snappedTime = round(proposedTime / viewModel.oneFrameDuration) * viewModel.oneFrameDuration
                    
                    if abs(snappedTime - viewModel.startTime) > viewModel.oneFrameDuration / 2 {
                        selectionFeedback.selectionChanged()
                    }
                    viewModel.startTime = snappedTime
                    
                } else { // End Handle
                    let newPosition = endHandlePosition(in: totalWidth) + dragValue.translation.width
                    
                    // The min position is the start handle's center PLUS a full handle width and the minimum gap.
                    let minimumPixelGap = totalWidth * (viewModel.oneFrameDuration / viewModel.videoDuration)
                    let minPosition = startHandlePosition(in: totalWidth) + handleWidth + minimumPixelGap
                    
                    let clampedPosition = min(totalWidth, max(newPosition, minPosition))

                    // ... (rest of the logic is the same)
                    let proposedTime = positionToTime(clampedPosition, totalWidth: totalWidth)
                    let snappedTime = round(proposedTime / viewModel.oneFrameDuration) * viewModel.oneFrameDuration

                    if abs(snappedTime - viewModel.endTime) > viewModel.oneFrameDuration / 2 {
                        selectionFeedback.selectionChanged()
                    }
                    viewModel.endTime = snappedTime
                }
            }
        }
        // ... (on drag end logic remains the same) ...
}
