**Task 1: Restore Functionality to the `Add Move` Flow**

    *   **`.promptForName` state:** After the video is processed, the view must transition to this new state. This state's UI must display:
        *   A preview of the selected video.
        *   A `TextField` prompting the user to "Enter move name...".
        *   A "Save Move" button.
    *   **Saving and Feedback:** When the user taps "Save Move," the new `Move` object is saved to Core Data. On completion, the view transitions to `.success(message: "Move saved!")` or `.error(message: "Save failed.")`. These feedback states should display their message for 2 seconds and then automatically transition the view back to the `.ready` state.
