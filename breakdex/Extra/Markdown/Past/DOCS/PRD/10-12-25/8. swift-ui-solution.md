The gray slab is the default pressed-state highlight that SwiftUI applies to buttons, navigation links, and sometimes list rows to show touch feedback, not a rendering bug. It can be reduced with .buttonStyle(.plain), removed with a custom ButtonStyle that draws no pressed state, or avoided entirely by using programmatic navigation instead of a tappable NavigationLink row.[1][2][3][4]

### ELI19
- SwiftUI controls have a built‑in “pressed” state that briefly overlays a gray/tinted highlight so interactions feel responsive.[2][4]
- This behavior comes from the environment’s ButtonStyle, whose default style adds decoration and a pressed visual effect.[3][4]
- PlainButtonStyle removes decoration but is allowed to still show a minimal pressed indicator, so some gray can remain by design.[5][2]
- To eliminate it completely, define a custom ButtonStyle and render the label unchanged regardless of configuration.isPressed.[4][3]
- NavigationLink labels and List rows also participate in this pressed/selection behavior, which can look like a wide gray overlay.[6][4]
- In those cases, apply a plain or custom style, clear the row background, or navigate programmatically to bypass the highlight entirely.[1][2][6]

### Examples
- Example 1 — Quick suppression  
  ```
  Button("Tap") { /* action */ }
    .buttonStyle(.plain)
  ```
  Using .buttonStyle(.plain) removes standard decoration and greatly reduces the default pressed overlay for a button or a link in scope.[7][2]

- Example 2 — No‑highlight button style  
  ```
  struct NoHighlightButtonStyle: ButtonStyle {
    func makeBody(configuration: Configuration) -> some View {
      configuration.label   // no visual change when pressed
    }
  }

  Button("Tap") { /* action */ }
    .buttonStyle(NoHighlightButtonStyle())
  ```
  A custom ButtonStyle that leaves the label unchanged removes pressed‑state visuals entirely and is reusable across the view hierarchy.[8][3][4]

- Example 3 — List/NavigationLink without gray flash  
  ```
  @State private var go = false

  NavigationLink("", destination: DetailView(), isActive: $go)
    .hidden()

  HStack { Text("Row") }
    .contentShape(Rectangle())
    .onTapGesture { go = true }
    .listRowBackground(Color.clear)

  // Optionally:
  // .scrollContentBackground(.hidden) on the List
  ```
  Triggering navigation programmatically avoids the NavigationLink pressed highlight, and clearing the row background prevents the list from drawing its default gray selection/background.[9][6][1]
