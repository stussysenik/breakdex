Setting up Brave MCP involves integrating the Brave Search API into AI tools like Claude Desktop via the Model Context Protocol (MCP), enabling web, image, news, video, and local searches directly in your AI workflows.[1] This requires a Brave Search API key and Node.js, with the server running via npx for simplicity or Docker for containerized deployment.[1]

## Prerequisites
Ensure Node.js version 22 or higher is installed, as it's required for the MCP server execution and aligns with your existing OpenSpec setup.[1] For Windows users, use a Node version manager to avoid installer issues during MCP configuration.[2] Docker is optional but recommended for isolated runs without local Node dependencies.[1]

## Obtain Brave Search API Key
Register or log in to a Brave Search API account at the developer dashboard.[2] Subscribe to a plan: the free tier suffices for personal use with 2,000 queries per month, or upgrade to Pro for advanced features like local search and AI summaries.[1] Navigate to "API Keys" in the left menu, click "Add API Key," name it (e.g., "MCP Setup"), select your plan, and generate the key—copy it securely as it's shown only once.[2]

## Install and Run the MCP Server
Use the npx method for quick setup without cloning the repo: run `npx -y @brave/brave-search-mcp-server` in your terminal, setting the `BRAVE_API_KEY` environment variable first (e.g., `export BRAVE_API_KEY=your_key_here` on macOS/Linux or `set BRAVE_API_KEY=your_key_here` on Windows).[1] For HTTP transport instead of default STDIO, add `--transport http` to the command or set `BRAVE_MCP_TRANSPORT=http` environment variable.[1] Alternatively, for Docker: pull the image with `docker pull mcp/brave-search:latest` and run `docker run -i --rm -e BRAVE_API_KEY=your_key_here mcp/brave-search`—this handles the server in a container without local Node.js.[1]

## Configure for Claude Desktop
Open Claude Desktop Settings, go to the Developer tab, and click "Edit Config" to access `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) or `%APPDATA%\Claude\claude_desktop_config.json` (Windows).[2] Replace or add the following JSON object, substituting `YOUR_API_KEY_HERE` with your actual key:[2]

```
{
  "mcpServers": {
    "brave-search": {
      "command": "npx",
      "args": [
        "-y",
        "@brave/brave-search-mcp-server"
      ],
      "env": {
        "BRAVE_API_KEY": "YOUR_API_KEY_HERE"
      }
    }
  }
}
```

For Docker in Claude config, use `"command": "docker"` and `"args": ["run", "-i", "--rm", "-e", "BRAVE_API_KEY", "mcp/brave-search"]` with the env as above.[1] Restart Claude Desktop; a hammer icon will appear in chats, indicating MCP tools are active—test by asking a search-requiring question like "Latest news on AI advancements."[2]

## Verification and Tools Usage
After setup, test the server standalone with `npx @modelcontextprotocol/inspector npx -y @brave/brave-search-mcp-server` to inspect available tools like `brave_web_search` (general queries), `brave_image_search` (images), or `brave_news_search` (news with freshness filters).[1] In your AI tool, invoke tools via natural prompts (e.g., "Search for recent breakdancing techniques"); parameters like `query`, `country`, `safesearch` ("strict" for filtered results), and `count` (up to 20 for web) can be specified for precision.[1] Monitor logs with `BRAVE_MCP_LOG_LEVEL=debug` environment variable for troubleshooting connection issues.[1]
