**Error:** `type 'any TrimmerViewModelProtocol' cannot conform to 'ObservableObject'`

**Code:**
```swift

```

**Issue:** SwiftUI's `@ObservedObject` requires a concrete type that conforms to `ObservableObject`, but `TrimmerViewModelProtocol` is a protocol type.

**Notes:**
- Only concrete types such as structs, enums and classes can conform to protocols
- This is a fundamental Swift/SwiftUI constraint
- The protocol already inherits from `ObservableObject`, but the type system doesn't allow protocol types with `@ObservedObject`

**Suggested Fix:** Change to `@ObservedObject var viewModel: any TrimmerViewModelProtocol` or use a generic constraint.
