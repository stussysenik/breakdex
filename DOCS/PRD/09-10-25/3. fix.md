## Restore rotate preview
- The preview uses CustomVideoPlayerView with a shared AVPlayer, but rotation isn’t recomputed when rotationQuarterTurns changes after initial setup; add an onChange(of:) to rebuild the playerItem with a rotated AVMutableVideoComposition when the value increments. [1]
- In CustomVideoPlayerView, add:  
  ```swift
  @State private var lastAppliedQuarterTurns = 0

  .onAppear { lastAppliedQuarterTurns = rotationQuarterTurns }

  .onChange(of: rotationQuarterTurns) { _, newValue in
    Task { await rebuildWithRotation(newValue) }
  }

  @MainActor
  private func rebuildWithRotation(_ quarterTurns: Int) async {
    guard quarterTurns != lastAppliedQuarterTurns else { return }
    lastAppliedQuarterTurns = quarterTurns
    if let asset = asset {
      do {
        let result = try await VideoTransformBuilder.build(asset: asset, quarterTurns: quarterTurns)
        let item = AVPlayerItem(asset: result.composition)
        item.videoComposition = result.videoComposition
        item.seekingWaitsForVideoCompositionRendering = true
        if case .playing(let existingPlayer) = playerState {
          existingPlayer.replaceCurrentItem(with: item)
        } else {
          playerState = .playing(player: AVPlayer(playerItem: item))
        }
      } catch {
        playerState = .error(message: "Failed to process video: \(error.localizedDescription)")
      }
    }
  }
  ```
  This mirrors the existing setup path but runs whenever the rotation changes, keeping the preview responsive and performant. [1]
