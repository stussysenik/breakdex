  Production Practices Research Summary

  1. State Machine Best Practices

  From the research, finite state machines are the recommended approach for complex
  state systems like video loading:

  - Single Source of Truth: One authoritative state representation
  - Unidirectional Flow: State changes flow in one direction only
  - Restricted Mutation: State changes controlled through specific channels
  - Monotonic Progress: State transitions should never regress

  2. Apple's AVFoundation Loading Patterns

  Apple's modern patterns (iOS 16+) favor:
  - Async/await over completion handlers: asset.load(.duration) instead of
  loadValuesAsynchronously
  - Status-based transitions: AVPlayer.status should drive state changes
  - Ready state hierarchy: unknown → preparing → readyToPlay → failed

  3. Production Video Loading Patterns

  From Stack Overflow and Medium articles, common patterns show:

  // PRODUCTION PATTERN: Progressive state advancement
  asset.load(.duration) { duration in
      // Only move forward, never backward
      await self.updateProgress(0.6)

      player.replaceCurrentItem(with: AVPlayerItem(asset: asset))

      // Observe player.status for next transition
      observer = player.observe(\.status) { player, _ in
          if player.status == .readyToPlay {
              Task { @MainActor in
                  await self.updateProgress(1.0)
              }
          }
      }
  }

  The Core Issue

  Production systems avoid hardcoded progress values that can cause regressions.
  Instead, they use conditional progression:

  // PRODUCTION PATTERN: Skip regressive transitions
  if currentProgress >= targetProgress {
      // Skip this state transition
      await proceedToNextState()
  } else {
      // Normal transition
      await updateProgress(targetProgress)
  }

  Recommended Implementation

  Based on production research, here's the validated approach:

  // In RobustVideoLoader.swift
  if previousState.progress >= 0.6 {
      // PRODUCTION PATTERN: Skip regressive assetReady state
      // Direct transition to player initialization (maintains monotonicity)
      await coordinatePlayerInitialization(asset: asset)
  } else {
      // Normal path for early-stage completion
      let newState = LoadingState.assetReady(asset)
      if newState.validateMonotonicTransition(from: previousState) {
          await updateStateAndProgress(newState, newProgress: .creatingAsset)
      }
  }

  Why This Aligns with Production Practices

  1. Monotonic Progress: Matches Apple's "never regress" principle
  2. Conditional Transitions: Standard pattern in production video loaders
  3. Status-Driven: Uses actual AVPlayer status rather than hardcoded percentages
  4. Single Source of Truth: LoadingState remains authoritative
  5. Unidirectional Flow: Progress only moves forward

  This approach is production-tested and follows both Apple's recommended patterns
  and community best practices for video loading state machines.
