Here’s the exact sequence of events causing the 0% stall:

1.  **Two Progress Values Exist:** The `UnifiedProgressEngine` uses two values for a smooth UI:

      * `_targetProgress`: The **actual** progress. When loading finishes, this is instantly set to `1.0`.
      * `unifiedProgress`: The **animated** value shown on screen. It smoothly animates towards the target on a 60Hz timer to look good.

2.  **The Backend is Extremely Fast:** Your loading service is so efficient that it reports 100% completion in under 100 milliseconds. This causes `_targetProgress` to jump from `0.0` to `1.0` almost instantly.

The check sees `unifiedProgress` is still `0.0`, it fails, and the app is now stuck. The completion logic is never run again.
