REGEX to find the multi-line:

Now I can see the pattern clearly! You have multi-line logger.info() calls where the opening parenthesis is on one line, the string content is on the next line with specific indentation, and the closing parenthesis is on a third line. Here's a regex pattern that will match these weirdly formatted expressions:

logger\.info\(\s*\n\s*"([^"]_UNIFIED_LOADING_DIAGNOSTICS[^"]_)"\s*\n\s*\)

Generalized version for any string content:
logger\.info\(\s*\n\s*"([^"]_)"\s_\n\s\*\)

More flexible version that handles various indentation levels:
logger\.info\(\s*\n\s*"([^"]_)"\s_\n\s\*\)

**Even more flexible version that handles whitespace between the string and closing parenthesis:**

```regex
logger\.info\(\s*\n\s*"([^"]*)"\s*\n?\s*\)

If you want to match other logger methods too (info, error, warning, debug):
logger\.(info|error|warning|debug)\(\s*\n\s*"([^"]*)"\s*\n\s*\)

Example usage:
- To find all UNIFIED_LOADING_DIAGNOSTICS log statements: logger\.info\(\s*\n\s*"([^"]*UNIFIED_LOADING_DIAGNOSTICS[^"]*)"\s*\n\s*\)
- To find all multi-line logger statements: logger\.(info|error|warning|debug)\(\s*\n\s*"([^"]*)"\s*\n\s*\)

The key parts of the regex:
- logger\.(info|error|warning|debug) - matches the logger method call
- \(\s*\n - matches opening parenthesis followed by newline
- \s*" - matches optional whitespace then opening quote
- ([^"]*) - captures any string content (this is what you can customize)
- "\s*\n - matches closing quote followed by newline
- \s*\) - matches optional whitespace then closing parenthesis

REGEX to comment out such multi-line:
⏺ Ah, I see! You need to comment out each line of the multi-line logger statement individually. Here are the correct regex patterns:

For commenting out each line separately:
(\s*)logger\.info\((\s*\n)(\s*)"([^"]*)"(\s*\n)(\s*)\)

Replace with:
\1// logger.info(\2\3// "\4"\5\6// )

Better approach - match and comment each line pattern:

Find multi-line logger patterns and replace with commented lines:
(\s*)logger\.info\((\s*\n)(\s*)"([^"]*)"(\s*\n)(\s*)\)

Replace with:
$1// logger.info($2$3// "$4"$5$6// )

For VS Code or similar editors, you might need to do multiple passes:

# ANSWER
First pass - comment the opening line:
^(\s*)logger\.info\((\s*)$
Replace with:
$1// logger.info($2

Second pass - comment the middle line:
^(\s*)"([^"]*)"(\s*)$
Replace with (only for logger lines):
$1// "$2"$3

Third pass - comment the closing line:
^(\s*)\)(\s*)$
Replace with (only for logger lines):
$1// )$2

Most reliable approach - match the entire block and add // to each line:
(?m)^(.*logger\.info\(.*)$\n^(.*)$\n^(.*\).*)$

Replace with:
// $1\n// $2\n// $3

This will transform:
        logger.info(
            "🎯 UNIFIED_LOADING_DIAGNOSTICS:  \(operation) [\(operationId)] - \(context)"
        )

Into:
        // logger.info(
        //     "🎯 UNIFIED_LOADING_DIAGNOSTICS:  \(operation) [\(operationId)] - \(context)"
        // )
```
