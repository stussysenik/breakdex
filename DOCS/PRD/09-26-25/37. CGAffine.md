The best approach to rotate a video 90 degrees in AVFoundation on iOS 18 is to use the video's preferredTransform property (a CGAffineTransform) from AVAssetTrack and adjust it by concatenating a 90-degree rotation transform. The preferredTransform encodes the video's orientation metadata, but sometimes it may need correction by adjusting its translation components.

Typically, to rotate a video 90 degrees clockwise, you can concatenate a CGAffineTransform rotation of 90 degrees (π/2 radians) to the existing preferredTransform for the video track, then apply this transform using AVMutableVideoCompositionLayerInstruction within an AVMutableVideoComposition. This transform can be set via setTransform(_:at:) on the layer instruction.

On iOS 18, this method remains valid and is the preferred way to handle video rotation programmatically, as AVFoundation uses the preferredTransform as the base orientation of the video. If the video’s visual orientation appears off, check the preferredTransform’s translation values and adjust accordingly.

Summary:
- Fetch the video track’s preferredTransform.
- Concatenate a 90-degree rotation transform (CGAffineTransform(rotationAngle: .pi / 2)).
- Apply this combined transform using AVMutableVideoCompositionLayerInstruction.
- Use this in an AVMutableVideoComposition during export or playback.

This approach respects the video's metadata and avoids re-encoding unless exporting the rotated video. For preview display, rotating the AVPlayerLayer with the transform is possible but less robust for file orientation.

This matches Apple developer advice and community solutions for iOS video rotation including recent iOS versions up to 18.[1][2][3]
