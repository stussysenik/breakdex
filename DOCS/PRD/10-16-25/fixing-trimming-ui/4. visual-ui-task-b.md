# PROMPT:
The core issues in the current design are **inconsistent vertical spacing**, **poorly grouped elements**, and a **non-standard trimming component**. This guide will fix that.

***

### ## Overall Layout Principles 📐

The layout should follow a simple vertical stack, with consistent spacing between logical groups. We'll use an **8-point grid system**, meaning all spacing and margins will be multiples of 8 (e.g., 8pt, 16pt, 24pt) for a clean, rhythmic feel.

The screen structure from top to bottom will be:
1.  **Video Preview**
2.  **Timecode Display** (`START`, `DURATION`, `END`)
3.  **Visual Timeline Trimmer** (The "Ruler")
4.  **Playback Controls** (`Play`, `Loop`, `Reset`)
5.  **Action Buttons** (`Cancel`, `Submit`)

***

### ## Component-by-Component Implementation

Here are the specific instructions for each section.

#### **1. Video Preview**
No changes are needed here. The video player appears fine. Ensure there is a **24pt margin** below it to create clear separation from the trimming controls.

#### **2. The Trimming Ruler (Combined Timecodes & Timeline)**
This is the most important change. The timecodes and the visual timeline are one logical unit and should be visually grouped together.

* **Timecode Display (`START`, `DURATION`, `END`):**
    * Position these three elements in a row *above* the visual timeline.
    * Use a standard `space-between` alignment so "START" is on the far left, "DURATION" is centered, and "END" is on the far right.
    * Keep the font style as is, but ensure the container for these timecodes spans the full width of the screen with a **16pt horizontal padding** on the left and right.

* **Visual Timeline Trimmer:**
    * **Remove the single blue bar.** Replace it with a proper timeline component that shows video frames (a "filmstrip").
    * The timeline should have **two distinct handles (grabbers)**: one for the **start** point and one for the **end** point. These handles should be easy to tap and drag.     * The selected portion of the timeline between the two handles should be highlighted (e.g., with a yellow or blue border).
    * A **playhead** (a thin vertical line) must be present to indicate the current playback position. It moves when the video is playing.
    * **Crucially, reduce the space** between the Timecode Display above and this Visual Timeline to just **8pt**.
    * The timeline's numeric markers (`00:08:12`, etc.) should be placed directly below the filmstrip with only **4pt of vertical space** separating them. This solidifies the "ruler" concept.

#### **3. Playback Controls**
This section contains the play button, loop icon, and reset link.

* Group these elements together horizontally.
* Place the large **Play button** on the left.
* Place the **Loop icon** and **Reset link** on the right.
* There should be a **32pt margin** above this control group to separate it from the trimming ruler. This gives the user's eyes a place to rest.

#### **4. Action Buttons (`Cancel` & `Submit`)**
This section needs the most breathing room to feel clean and intentional. By removing the large empty blue box from the original design, we create this space naturally.

* Position these two buttons near the bottom of the screen, just above the main tab bar.
* There should be a significant amount of **flexible vertical space** between the Playback Controls and these Action Buttons.
* The buttons should be in a horizontal row. The **`Cancel` button** (secondary style: light gray or outlined) should be on the left, and the **`Submit` button** (primary style: solid blue) should be on the right.
* Ensure there's a **16pt margin below** the buttons to separate them from the app's bottom tab bar.
* The buttons should have a gap between them (e.g., 12pt) and together span the width of the screen with **16pt horizontal padding** on each side.

By following these spacing and component guidelines, the interface will feel balanced, intuitive, and adhere to a clean, minimalistic aesthetic. ✨
