# ContentShape

expl: contentShape defines an invisible interaction area that makes the entire view tappable, not just the text and icons inside it. The Rectangle itself is never actually shown on screen - it's just used as a geometric shape to create the invisible tap boundary that covers the whole row.

# Apple-native colors
Response:
  iOS Semantic Colors:
  - .label - Primary text color
  - .secondaryLabel - Secondary text color
  - .tertiaryLabel - Tertiary text color

  Other common semantic colors:
  - .systemBackground - Main background
  - .secondarySystemBackground - Content background
  - .systemGray6, .systemGray5, etc. - Grayscale system colors

  These automatically adapt to:
  - Light Mode → Appropriate dark colors
  - Dark Mode → Appropriate light colors
  - High Contrast → Enhanced contrast variants
  - Accessibility settings → User's preferred contrast levels

  Using these ensures your app follows iOS design guidelines and works properly across all appearance modes and accessibility settings.
