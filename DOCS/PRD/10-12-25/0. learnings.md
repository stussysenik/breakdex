# ContentShape

expl: contentShape defines an invisible interaction area that makes the entire view tappable, not just the text and icons inside it. The Rectangle itself is never actually shown on screen - it's just used as a geometric shape to create the invisible tap boundary that covers the whole row.

- https://developer.apple.com/documentation/swiftui/view/contentshape(_:_:eofill:)
