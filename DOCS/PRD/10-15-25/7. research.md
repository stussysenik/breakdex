# RESEARCH:
Based on the provided user interface, here is a direct and precise execution plan for integrating trimming and rotation functionality from a usability perspective.

### Trimming Functionality Execution

The core trimming interface is already present but can be refined for better precision and feedback.

*   **Refine the Slider to a Range Selector:** Modify the existing "Trim Range" slider to function as a dedicated range selector. It should have two distinct, draggable handles: a "Start" handle on the left and an "End" handle on the right.
*   **Real-time Feedback:** As the user drags either handle, the video preview window should instantly jump to that specific frame, providing precise visual context for the cut. Simultaneously, the "Start" and "End" timecode displays below the slider must update in real-time. The "Duration" label within the trim box should also dynamically calculate and display the new length of the selected clip.
*   **Playback Preview:** When the user presses the play icon on the main video player, playback should be looped and confined *only* to the currently selected trim range. This allows the user to review their selection accurately before committing.
*   **Scrubbing:** The main blue dot (labeled "Current") should remain, allowing the user to scrub through the timeline. However, its movement should be constrained between the Start and End handles of the trim range.

### Rotation Functionality Integration

Rotation controls should be added directly into this editing view to maintain a seamless workflow without navigating to a different screen.

*   **Add a Rotation Control Row:** Directly below the video preview and above the "Duration" and "File Size" text, insert a new section or a simple horizontal row of icons for rotation.
*   **Implement Rotation Buttons:** This row will contain two primary icon-based buttons:
    *   **Rotate Left (Counter-Clockwise):** An icon showing an arrow curving to the left.
    *   **Rotate Right (Clockwise):** An icon showing an arrow curving to the right.
    (or just keep one whichever is easier to implement)
*   **Instant Visual Feedback:** When a user taps either rotation button, the video in the preview window should animate a 90-degree turn in the corresponding direction. This change is a temporary preview and is not permanently applied until the user confirms.
*   **Unified Action Buttons:** The existing `Reset` and `Apply Tr...` (Apply Trim) buttons will now manage both trimming and rotation states.
    *   **Reset Button:** Tapping `Reset` will revert *both* the trim range to the full video length and the video's orientation to its original state.
    *   **Apply Button:** The button text should change from "Apply Trim" to a more general "Apply". Tapping this will process both the selected trim range and the final rotation state in a single operation.
