#### **✅ Step 2: Refactor Progress Engine for Determinism (Crucial Change)**

  * **Objective**: Replace the predictive progress model with a deterministic, stage-weighted model that mirrors the backend reality.
  * **Action**:
    1.  Identify and document the discrete stages of the video loading pipeline from the legacy `VideoLoadingProgress` enum.
        ```
        GrepTool(pattern="case .*:", path="AddMoveUnifiedState.swift", flags="-A 1") // Look for handleVideoLoadingProgress function
        ```
    2.  Assign a fixed weight to each stage. These weights must sum to 1.0. Example:
          * `.initializing`: 0.05
          * `.downloading`: 0.50
          * `.transferring`: 0.25
          * `.validating`: 0.15
          * `.validatingTrimmer`: 0.05 (This stage's completion brings the total to 1.0)
    3.  Modify the `UnifiedProgressEngine` to calculate `unifiedProgress` based on these weights. The progress for a given stage is multiplied by its weight and added to the sum of the weights of all completed preceding stages.
        ```swift
        // In UnifiedProgressEngine.swift, replace smoothing logic with this:
        private let stageWeights: [LoadingPhase: Double] = [
            .initializing: 0.05,
            .downloading: 0.50,
            .transferring: 0.25,
            .validating: 0.15,
            .finalizing: 0.05 // Includes .validatingTrimmer
        ]

        private func calculateDeterministicProgress(phase: LoadingPhase, phaseProgress: Double) -> Double {
            var totalProgress = 0.0
            // Add weights of all completed phases before the current one
            for (p, weight) in stageWeights {
                if p.order < phase.order { // Assuming LoadingPhase has an order property
                    totalProgress += weight
                }
            }
            // Add the progress of the current phase
            totalProgress += (stageWeights[phase] ?? 0.0) * phaseProgress
            return totalProgress
        }
        ```
  * **Verification**: Write a unit test suite for `calculateDeterministicProgress` that provides various `phase` and `phaseProgress` inputs and asserts that the output `totalProgress` is mathematically correct based on the predefined weights.
