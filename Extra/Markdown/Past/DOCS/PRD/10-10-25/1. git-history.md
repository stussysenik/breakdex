> what's soft reset again 

⏺ A soft reset (git reset --soft <commit>) moves your branch pointer back to a previous commit while
  keeping all your changes staged (in the index/staging area).

  What happens with git reset --soft 01473c4:

  - Your branch essential now points to commit 01473c4
  - All the changes from commits between 01473c4 and deed114 become staged changes
  - Your working directory files remain unchanged
  - git status will show all those changes as "Changes to be committed"

  Comparison to other resets:

  - Soft reset (--soft): Changes become staged
  - Mixed reset (default, no flag): Changes become unstaged
  - Hard reset (--hard): Changes are completely discarded

  So in your case, after git reset --soft 01473c4, the changes from deed114 (your .md files and
  whatever else changed) will be staged and ready for you to selectively commit or unstage.

> what's git clean -fd 

⏺ git clean -fd removes untracked files and directories from your working directory.

  What it does:

  - -f: force (actually remove the files)
  - -d: also remove untracked directories

  What it removes:

  - Files that git doesn't track (not in your working tree)
  - Directories that git doesn't track
  - Build artifacts, temporary files, etc.

  What it does NOT remove:

  - Tracked files (even if modified)
  - Staged changes
  - Committed changes

  So git clean -fd + git reset --hard HEAD gives you a completely clean working directory that matches your latest commit
  exactly, removing any "junk" that might have been created during your process.

⏺ To amend the latest git commit message and reflect it on the remote, you need to:
