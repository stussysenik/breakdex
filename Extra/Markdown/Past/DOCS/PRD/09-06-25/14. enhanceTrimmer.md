% Facts supplied at runtime
duration(D).              % Total video duration in seconds.  % [6]
width(W).                 % Timeline pixel width.  % [2]
fps(F).                   % Nominal frames per second; derive frame_duration FD = 1/F.  % [6]
min_gap(FD).              % Minimum allowed gap between start and end = one frame.  % [6]

% Mapping position -> time and time -> snapped frame time
raw_time(X,T) :- width(W), duration(D), T is (X/W)*D.  % [6][7]
frame_index(T,K) :- fps(F), FD is 1/F, K is round(T/FD).  % [6]
snap_time(T,TS) :- frame_index(T,K), fps(F), FD is 1/F, TS is K*FD.  % [6]

% Constraints for handles (no overlap, clamped to bounds)
valid_range(S,E) :- S >= 0, duration(D), E =< D, fps(F), FD is 1/F, E >= S + FD.  % [6]
clamp_start(ProposedS,E,S) :- fps(F), FD is 1/F, S0 is max(0, min(ProposedS, E-FD)), snap_time(S0,S).  % [6]
clamp_end(ProposedE,S,E)   :- fps(F), FD is 1/F, duration(D), E0 is min(D, max(ProposedE, S+FD)), snap_time(E0,E).  % [6]

% Input loop (high-fidelity touch -> handle position), independent of preview.  % [2]
update_handle_from_touch(Handle,TouchX,TouchY,PrevPos,NewPos) :-
  precision_scale(TouchY,Scale),  % vertical-offset and velocity scaling.  % [8][9]
  NewPos is PrevPos + (TouchX * Scale).  % [8][9]

% Haptic detent when frame index changes during drag.  % [5]
detent_if_frame_changed(PrevT,NewT) :- frame_index(PrevT,K1), frame_index(NewT,K2), K1 =\= K2 -> play_tick ; true.  % [5]

% Seek scheduler: single in-flight seek; coalesce target time; never overlap seeks.  % [3][10]
schedule_seek(LatestTarget) :- not(seeking) -> issue_seek(LatestTarget) ; remember(LatestTarget).  % [3]
on_seek_complete :- clear_seeking, (has_remembered(T) -> issue_seek(T) ; true).  % [3]

% Fallback preview if seeks are slow: step frames or use image generator with tight tolerances.  % [10][11][12]
fallback_preview_enabled :- measured_seek_latency_ms(MS), MS > Threshold.  % [10]

## Secret sauce from proven cases
- High‑fidelity input via coalesced touches prevents the “dot isn’t keeping up with the finger” effect; use a pan‑recognizer bridge or equivalent to sample at display rate and with predicted touches. [1][5]
- Never bind handle motion to media seeks; queue a single in‑flight seek and coalesce the latest target so the UI leads and the preview trails predictably. [2][6]
- Quantize to frame‑exact CMTime using an asset‑appropriate timescale (e.g., 600) or the precise frame duration, then enforce a one‑frame minimum gap so points never touch. [7][8]
- Provide velocity and vertical‑offset precision scrubbing so the same gesture supports coarse moves and frame‑by‑frame adjustments without mode switches. [9][10]
- Emit haptic detents once per snapped frame change and light impacts on grab/release to confirm precision without visual noise. [4]
- Eliminate implicit animations on drag‑driven state to avoid “invalid animatable sample” warnings and perceived lag. [11][12]
- Use systemBlue for the active range and handles, true‑black action background, and ≥44 pt hit targets to keep it minimal, accessible, and unmistakably tappable. [3][13]

### Architecture
- Input loop: converts high‑rate touch samples to handle X with velocity/vertical precision scaling; updates view state immediately. [1][9]
- Quantizer: converts X→raw time→snapped CMTime and enforces the one‑frame gap; emits detent haptics on index change. [7][4]
- Seek scheduler: coalesces latest target, issues next seek in completion, and applies tolerance policy; switches to fallback preview if latency threshold exceeded. [2][6][14]
- Export contract: downstream creates CMTimeRange from snapped start/end, guaranteeing parity with preview boundaries. [8][16]

### Algorithms and tolerances
- Timescale: prefer 600; if asset fps known, derive $$\Delta_{frame}=1/\text{fps}$$ and timescale $$= \max(600, \text{fps}\times 10)$$ to limit rounding error. [7][17][18]
- Seek tolerances: use zero/zero for frame‑steppable items; otherwise zero/+$$\infty$$ to arrive not before target; fall back to +$$\infty$$/+$$\infty$$ for max throughput on slow assets. [6]
- Latency threshold: measure seek completion times; if mean > N ms during drag, enable fallback preview until drag ends, then resume normal playback. [2][6]
