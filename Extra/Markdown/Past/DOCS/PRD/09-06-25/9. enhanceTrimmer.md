#### **1. Specify (Refinement)**

This iteration perfects the trimmer's tactile feel and visual integration. The goals are:
1.  **Guarantee handle precision** by enforcing strict boundary conditions.
2.  **Refine the layout** so the bottom action buttons feel like a natural extension of the app's main navigation, not a separate, floating panel.
3.  **Ensure the handles are effortlessly "grabbable"** while preventing them from ever overlapping.

#### **2. Experience (Refined)**

*   **Layout & Spacing (New):**
    *   The trimmer's action buttons (`Back`, `[Contextual]`, `Save Trim`) must be visually anchored. Instead of floating, they should reside within a container that aesthetically matches the app's primary bottom navigation bar (e.g., using a similar background material or height).
    *   **Vertical Spacing:** The space between the time readouts (`Start`, `Duration`, `End`) and this new bottom bar container will be flexible, ensuring the bar is anchored to the bottom safe area. This creates a clear separation and visual hierarchy.
*   **Timeline Control (Refined):**
    *   **Track:** A thin, horizontal line. The segment between the handles is tinted with the app's primary color (Apple Blue), while the outside segments are a dimmer, secondary color.
    *   **Handles:** Two circular thumb controls. The left handle is visually a circle, while the right handle can be the same. Both must have large, invisible touch targets.
    *   **Transient Labels:** As a handle is dragged, a timestamp appears directly above the timeline at that handle's position (e.g., "00:04..."). This provides immediate feedback without cluttering the handle itself.
*   **Interaction Model (Refined & Clarified):**
    *   **Drag & Precision:** The core interaction is dragging the handles. Precision is achieved through:
        1.  **Frame Snapping:** The handles must snap to discrete frame boundaries of the video, preventing "in-between" states.
        2.  **Haptic Feedback:** A subtle tap is provided when a drag begins, ends, and as the handle "ticks" over frame boundaries.
    *   **No Animations:** All positional changes are immediate. There is no easing or animation on the handle's movement to ensure the user feels directly connected to the frame they are selecting.

#### **3. Functional Requirements (Updated)**

*   **FR12 (New): Handle Boundary Enforcement:**
    *   The `startTime` handle must be initialized at `CMTime.zero` and cannot be moved to a negative time.
    *   The `endTime` handle cannot be moved to a time less than the `startTime`.
    *   **No Overlap:** The system must enforce a minimum separation between the handles, equivalent to **one frame** of the video's duration. They can never occupy the same timestamp.
*   **FR13 (New): Anchored Bottom Bar:** The action buttons must be placed within a container view that is styled to match the app's existing bottom tab bar, creating a cohesive and native look.
*   **FR14 (New): Effortless Drag Initiation:** The touch target for each handle must be significantly larger than its visual representation (minimum **44x44 points**), ensuring the user can grab it easily without precise aiming.

#### **4. Tasks (Updated)**

*   **Task 1: Implement Anchored Bottom Bar:**
    *   Create a container `HStack` for the `Back`, `[Contextual]`, and `Save Trim` buttons.
    *   Apply a background material and padding to this container so it visually aligns with the app's main tab bar.
    *   Use a `VStack` with a `Spacer` to push this new bar to the bottom of the screen, anchoring it above the safe area.
*   **Task 2: Enforce Strict Handle Boundaries:**
    *   In the gesture's update logic, add checks to clamp the handle's position.
    *   `newStartTime = max(CMTime.zero, min(newStartTime, endTime - oneFrameDuration))`
    *   `newEndTime = min(videoDuration, max(newEndTime, startTime + oneFrameDuration))`
*   **Task 3: Refine Handle Hit Targets:**
    *   Use SwiftUI's `.contentShape(Rectangle())` on a larger, invisible frame surrounding each handle's visual representation to guarantee a 44x44pt touch area.
*   **Task 4: Implement Transient Timestamp Labels:**
    *   During a drag gesture, display a `Text` view positioned above the timeline, aligned with the handle's horizontal position. Its visibility is tied to the gesture's active state.

#### **5. Acceptance Criteria**

*   **AC1:** The bottom action buttons are contained in a bar that is visually cohesive with the app's main navigation.
*   **AC2:** The start and end handles can never be dragged to the same time; a minimum one-frame gap is always maintained.
*   **AC3:** The start handle is always initialized at the absolute beginning of the video (`00:00.00`).
*   **AC4:** Users can reliably grab and drag the handles on the first attempt, even with imprecise finger placement, due to the enlarged touch targets.
