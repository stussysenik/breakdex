### **Objective**

Refactor the video loading pipeline to provide an accurate, real-time progress indicator and establish a robust, single-responsibility architecture. The end goal is to eliminate redundant components and ensure a smooth, reliable transition from video selection to the trimming UI.

---

### **Phase 1: Consolidate and Enhance the `VideoLoadingService`**

* **Target File**: `VideoLoadingService.swift`
* **Actions**:
    1.  **Merge Asset Loading Logic**: Absorb the responsibilities of the `UpdatedVideoAssetLoader`. The `VideoLoadingService` will now be directly responsible for fetching the `AVAsset` from the `PHAsset` identifier.
    2.  **Implement an Event-Driven Stream**: Modify the primary `loadPHAssetWithProgress` function. It must return an `AsyncThrowingStream` that yields a structured `VideoLoadEvents` enum. This enum must be enhanced to differentiate between `progress` events and a final `success` event that contains the fully prepared `AVPlayer` and `AVAsset`.
    3.  **Implement Real-Time Progress**: Remove all `Task.sleep` and `while` loop heuristics for faking progress. The new progress reporting must be based on three distinct, *real system events*:
        * **Stage 1 (0-70%)**: Continue using the `PHVideoRequestOptions.progressHandler` for accurate iCloud download progress.
        * **Stage 2 (70-85%)**: After the asset is downloaded, asynchronously load its essential properties (`.duration`, `.tracks`, etc.). Emit a progress event to 85% only upon successful completion of this task.
        * **Stage 3 (85-100%)**: After creating the `AVPlayerItem`, use the refactored `PlayerItemStatusMonitor` to monitor the actual buffer size via `loadedTimeRanges`. The progress from 85% to 100% must be directly proportional to the amount of data buffered, ensuring 100% is reached only when the player is truly ready for interaction.

---

### **Phase 2: Refactor the `PlayerItemStatusMonitor` for True Readiness**

* **Target File**: `PlayerItemStatusMonitor.swift`
* **Actions**:
    1.  **Enhance Readiness Check**: Modify the `waitForReadyToPlay` method to be the core of our buffer monitoring. Remove the premature exit that checks only for the `.readyToPlay` status.
    2.  **Implement Progress Reporting**: The function must now accept a callback closure that it can use to report the buffering progress as a `Double` (from 0.0 to 1.0).
    3.  **Define Completion Criteria**: The monitor should only complete (and resolve its async task) when a sufficient buffer is acquired (e.g., 2-3 seconds of video) or when the `isPlaybackLikelyToKeepUp` flag becomes true.

---

### **Phase 3: Simplify the `UnifiedVideoPlayerViewModel`**

* **Target File**: `UnifiedVideoPlayerViewModel.swift`
* **Actions**:
    1.  **Remove Loading Responsibility**: Delete the `loadVideoWithProgress` function and all associated properties and logic (`loadingTask`, `progress`, `etaSeconds`, etc.).
    2.  **Refactor Initializer**: The view model's `init` method must be changed. It will no longer accept an `AVAsset` to load. Instead, it must accept a pre-configured `AVPlayer` instance that is already loaded and ready for playback. Its sole responsibility will be to manage the state of that player.

### **Phase 4: Cleanup and Final Integration**

### \#\# 1. `VideoLoadingService.swift` (Enhanced)

This service is now the single source of truth for the entire video loading pipeline. It fetches the asset, monitors real progress across three stages, and yields a fully prepared `AVPlayer`.

```swift
import Foundation
import AVFoundation
import Photos
import os.log

// MARK: - Progress Events
public enum VideoLoadEvent {
    case progress(fraction: Double, status: String)
    case success(player: AVPlayer, asset: AVAsset)
}

// MARK: - Video Loading Service
@MainActor
public final class LiveVideoLoadingService {
    private let logger = Logger(subsystem: "com.breakingflashcards", category: "VideoLoadingService")
    private var imageRequestID: PHImageRequestID?
    
    public init() {}
    
    public func loadPHAssetWithProgress(_ asset: PHAsset) -> AsyncThrowingStream<VideoLoadEvent, Error> {
        AsyncThrowingStream { continuation in
            // Cancel any previous request before starting a new one.
            cancelCurrentOperation()

            let options = PHVideoRequestOptions()
            options.isNetworkAccessAllowed = true
            options.deliveryMode = .highQualityFormat // Request high quality for trimming.
            
            // STAGE 1: iCloud Download Progress (0% -> 70%)
            options.progressHandler = { progress, _, _, _ in
                let scaledProgress = progress * 0.7 // Scale to 0-70% range
                let status = progress < 0.9 ? "Downloading from iCloud..." : "Finalizing download..."
                continuation.yield(.progress(fraction: scaledProgress, status: status))
            }

            self.imageRequestID = PHImageManager.default().requestAVAsset(
                forVideo: asset,
                options: options
            ) { avAsset, _, info in
                Task {
                    do {
                        if let error = info?[PHImageErrorKey] as? Error {
                            continuation.finish(throwing: error)
                            return
                        }
                        guard let loadedAsset = avAsset else {
                            throw NSError(domain: "VideoLoadingService", code: -1, userInfo: [NSLocalizedDescriptionKey: "AVAsset is nil."])
                        }

                        // STAGE 2: Loading Asset Properties (70% -> 85%)
                        continuation.yield(.progress(fraction: 0.7, status: "Loading video metadata..."))
                        try await loadedAsset.load(.isPlayable, .duration, .tracks)
                        continuation.yield(.progress(fraction: 0.85, status: "Preparing player..."))
                        
                        // STAGE 3: Player Item Buffering and Readiness (85% -> 100%)
                        let playerItem = AVPlayerItem(asset: loadedAsset)
                        let player = AVPlayer(playerItem: playerItem)
                        let monitor = PlayerItemStatusMonitor(playerItem: playerItem)

                        try await monitor.awaitReadyAndBuffered(onProgress: { bufferProgress in
                            // Scale buffer progress to the 85-100% range.
                            let overallProgress = 0.85 + (bufferProgress * 0.15)
                            continuation.yield(.progress(fraction: overallProgress, status: "Buffering video for preview..."))
                        })
                        
                        // YIELD FINAL RESULT
                        continuation.yield(.success(player: player, asset: loadedAsset))
                        continuation.finish()

                    } catch {
                        continuation.finish(throwing: error)
                    }
                }
            }
        }
    }
    
    public func cancelCurrentOperation() {
        if let requestID = imageRequestID {
            PHImageManager.default().cancelImageRequest(requestID)
            imageRequestID = nil
            logger.info("🛑 Cancelled pending PHImageManager request.")
        }
    }
    
    deinit {
        cancelCurrentOperation()
    }
}
```

### \#\# 2. `PlayerItemStatusMonitor.swift` (Refactored)

This monitor has been updated to perform a more sophisticated readiness check based on the actual buffer status, and it now reports its progress. The premature exit has been removed.

```swift
import Foundation
import Combine
import AVFoundation
import OSLog

@MainActor
public class PlayerItemStatusMonitor {
    private let logger = Logger(subsystem: "BreakingFlashcards", category: "PlayerItemStatusMonitor")
    private let playerItem: AVPlayerItem
    
    public init(playerItem: AVPlayerItem) {
        self.playerItem = playerItem
    }
    
    public enum MonitorError: Error, LocalizedError {
        case timeoutExceeded
        case playerItemFailed(Error?)
        
        public var errorDescription: String? {
            switch self {
            case .timeoutExceeded: return "Player item readiness monitoring timed out."
            case .playerItemFailed(let error): return "Player item failed: \(error?.localizedDescription ?? "Unknown error")"
            }
        }
    }
    
    /// Waits until the player item is ready and has buffered a sufficient duration for smooth interaction.
    /// Reports progress of the buffering process via a callback.
    public func awaitReadyAndBuffered(
        timeout: TimeInterval = 15.0,
        onProgress: @escaping @MainActor (Double) -> Void
    ) async throws {
        let requiredBufferDuration: TimeInterval = 2.0 // Require 2 seconds of buffer for "readiness"

        try await withThrowingTaskGroup(of: Void.self) { group in
            // Timeout Task
            group.addTask {
                try await Task.sleep(nanoseconds: UInt64(timeout * 1_000_000_000))
                throw MonitorError.timeoutExceeded
            }
            
            // Readiness Monitoring Task
            group.addTask {
                try await withCheckedThrowingContinuation { (continuation: CheckedContinuation<Void, Error>) in
                    var observers = [NSKeyValueObservation]()
                    var hasResumed = false

                    let cleanupAndResume: (Result<Void, Error>?) -> Void = { result in
                        guard !hasResumed else { return }
                        hasResumed = true
                        observers.forEach { $0.invalidate() }
                        observers.removeAll()
                        if let result = result {
                            continuation.resume(with: result)
                        } else {
                            continuation.resume()
                        }
                    }

                    let checkReadiness = {
                        guard self.playerItem.status == .readyToPlay else {
                            if self.playerItem.status == .failed {
                                cleanupAndResume(.failure(MonitorError.playerItemFailed(self.playerItem.error)))
                            }
                            return
                        }
                        
                        guard let firstRange = self.playerItem.loadedTimeRanges.first?.timeRangeValue else {
                            onProgress(0) // No buffer yet
                            return
                        }
                        
                        let bufferedDuration = CMTimeGetSeconds(firstRange.duration)
                        let progress = min(1.0, bufferedDuration / requiredBufferDuration)
                        onProgress(progress)

                        if bufferedDuration >= requiredBufferDuration || self.playerItem.isPlaybackBufferFull || self.playerItem.isPlaybackLikelyToKeepUp {
                            cleanupAndResume(nil)
                        }
                    }
                    
                    observers.append(self.playerItem.observe(\.status, options: [.new, .initial]) { _, _ in
                        Task { @MainActor in checkReadiness() }
                    })

                    observers.append(self.playerItem.observe(\.loadedTimeRanges, options: [.new, .initial]) { _, _ in
                        Task { @MainActor in checkReadiness() }
                    })
                }
            }

            // Await the first task to finish and cancel the other.
            try await group.next()
            group.cancelAll()
        }
    }
}
```
