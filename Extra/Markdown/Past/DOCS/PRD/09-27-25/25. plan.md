The system uses multiple, overlapping services for video loading (`AddMoveVideoLoader`, `PhotosImportService`, `VideoLoadingService`, `ImportManager`), leading to inconsistent implementations. Specifically, two of these services load entire video files into memory, creating a significant risk of crashes.

### 1\. Categorical Systems Analysis: Ideal vs. Observed

#### 1.1. The Ideal Category ($C_{ideal}$): A Model of Correctness

[cite\_start]As outlined in your specification [cite: 57-59], the ideal system is a composition of pure, total functions (morphisms) operating on well-defined data states (objects).

  * **Objects:**

      * `Selection`: The user's chosen `PhotosPickerItem`.
      * `TempVideoURL`: A local URL to the full, unmodified video file.
      * `EditParams`: A tuple `(CMTimeRange, CGAffineTransform)` representing the user's trim and rotation.
      * `ProcessedVideoURL`: A local URL to the video *after* trim and rotation have been applied.
      * `SavedPHAsset`: The final, persistent `PHAsset` in the "BreakDex" album.
      * `MoveEntity`: The final `NSManagedObject` in CoreData with stable references to the `SavedPHAsset`.

  * **Morphisms (State Transitions):**

      * `transfer: Selection → TempVideoURL`: A memory-efficient file transfer.
      * `process: (TempVideoURL, EditParams) → ProcessedVideoURL`: Applies edits. [cite\_start]**This must be an isomorphism** with respect to visual data, ensuring WYSIWYG[cite: 73].
      * [cite\_start]`persist: ProcessedVideoURL → SavedPHAsset`: An atomic, idempotent function that saves the video to the "BreakDex" album[cite: 76].
      * `finalize: SavedPHAsset → MoveEntity`: Creates the CoreData record.

The entire flow is a composition: `flow = finalize \circ persist \circ process \circ transfer`. [cite\_start]For the system to be correct, this composition must always result in a state where the video in `MoveEntity` visually matches the `EditParams` applied to the `Selection`[cite: 83].

#### 1.2. The Observed Category ($C_{observed}$): Modeling the Flaws

The current codebase represents a flawed reality where morphisms are buggy or inefficient.

  * **Functor of Inefficiency (Memory Overload):**
    The `transfer` morphism is implemented incorrectly in two key places. Both `AddMoveVideoLoader.swift` and `PhotosImportService.swift` contain a fallback path that loads the entire video into memory as a `Data` object.

      * **`AddMoveVideoLoader.swift`:** `guard let data = try await item.loadTransferable(type: Data.self)`
      * **`PhotosImportService.swift`:** `guard let data = try await item.loadTransferable(type: Data.self)`
        [cite\_start]This represents an **inefficient functor**[cite: 129]. It maps the ideal concept of "a video file" to an implementation that is not scalable and will fail for the large, high-quality footage typical of the "Athlete" persona. This is a critical failure pattern.

  * **Isomorphism Failure (The Rotation Bug):**
    [cite\_start]The specification correctly identifies that a naive `AVAssetExportSession` fails to apply rotation, breaking the WYSIWYG principle [cite: 89-92]. This means the `process` morphism is not an isomorphism; it fails to preserve the visual structure (`CGAffineTransform`) of the user's edits. The current code lacks a dedicated `VideoProcessor` to handle this correctly.

  * **Non-Commutative Diagram (The Album Race Condition):**
    [cite\_start]The specification warns against a naive "check-if-album-exists-then-create" logic, which is prone to race conditions when adding videos in quick succession [cite: 94-96]. This breaks the idempotency of the `persist` morphism. [cite\_start]Under concurrency, the order of operations becomes unpredictable, leading to a **non-commutative diagram** where multiple "BreakDex" albums can be created [cite: 101-102]. The fix requires an atomic operation.

  * **Object Gap (Incomplete State):**
    [cite\_start]The specification astutely identifies a major blind spot: `PHAsset.localIdentifier` is not stable across devices with iCloud Photos [cite: 261-262]. A `MoveEntity` that only stores this identifier is an incomplete object. [cite\_start]This is an **object gap** [cite: 131] that will lead to videos appearing "missing" on a user's other devices.
