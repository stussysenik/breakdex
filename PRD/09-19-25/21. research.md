Short answer: There isn’t a public transform(for:at:) getter on AVVideoCompositionLayerInstruction; to read the “current” transform, query the transform ramp with getTransformRamp(for:start:end:timeRange:) at the desired CMTime and, if a ramp exists, interpolate between the returned start and end transforms over that timeRange, or if a fixed transform was set, track that value explicitly when configuring the instruction [1][2][3]. Apple also notes that legacy mutating setters like setTransform(_:at:) are superseded by using the configuration-based API, but the read pattern still relies on querying ramps rather than a direct instantaneous getter [4][5].

### What the API provides
- getTransformRamp(for:start:end:timeRange:) returns the start and end CGAffineTransform plus the effective CMTimeRange if a ramp covering that time exists, allowing computation of the transform progression at an arbitrary CMTime [1][2].  
- setTransform(_:at:) applies a fixed transform from a given time onward (no automatic readback API is provided to fetch that specific value later) [3].  
- setTransformRamp(fromStartTransform:toEndTransform:timeRange:) defines a linear ramp between two transforms over a time range (again, readable via getTransformRamp) [6].  
- Apple’s docs indicate newer usage should prefer AVVideoCompositionLayerInstruction.Configuration over the older mutating setters, but this does not introduce a transform(for:at:) reader on the instruction itself [4][5].

### Getting the current transform
- Query getTransformRamp(for:start:end:timeRange:) at the target time; if it returns true, compute progress $$p = \frac{t - t_0}{\Delta t}$$ and interpolate translation/scale/rotation components between start and end transforms for the instantaneous value applied by the composition [1][2][7].  
- AVFoundation tweening semantics for affine transforms are linear across the ramp, so decompose both CGAffineTransforms (e.g., translation, rotation angle via atan2, and scale) and interpolate each component before recomposing a CGAffineTransform for the current time [7][8].  

Example (Swift):
```swift
var start = CGAffineTransform.identity
var end = CGAffineTransform.identity
var tr = CMTimeRange.invalid

if layerInstruction.getTransformRamp(for: time, start: &start, end: &end, timeRange: &tr) {
    let t0 = CMTimeGetSeconds(tr.start)
    let dt = CMTimeGetSeconds(tr.duration)
    let p = max(0, min(1, (CMTimeGetSeconds(time) - t0) / dt))

    func decompose(_ t: CGAffineTransform) -> (tx: CGFloat, ty: CGFloat, sx: CGFloat, sy: CGFloat, angle: CGFloat) {
        let tx = t.tx, ty = t.ty
        let sx = sqrt(t.a * t.a + t.c * t.c)
        let sy = sqrt(t.b * t.b + t.d * t.d)
        let angle = atan2(t.b, t.a)
        return (tx, ty, sx, sy, angle)
    }

    let s0 = decompose(start)
    let s1 = decompose(end)

    func lerp(_ a: CGFloat, _ b: CGFloat, _ p: CGFloat) -> CGFloat { a + (b - a) * p }

    let angle = lerp(s0.angle, s1.angle, p)
    let sx = lerp(s0.sx, s1.sx, p)
    let sy = lerp(s0.sy, s1.sy, p)
    let tx = lerp(s0.tx, s1.tx, p)
    let ty = lerp(s0.ty, s1.ty, p)

    let current = CGAffineTransform(translationX: tx, y: ty)
        .rotated(by: angle)
        .scaledBy(x: sx, y: sy)

    // use `current` as the “effective” transform at `time`
}
```

### Practical notes
- If no ramp covers the time (getTransformRamp returns false), the instruction has no readable transform at that moment; store fixed transforms when calling setTransform(_:at:) if later retrieval is required at edit time [2][3].  
- When rotating portrait content, additional translation is often necessary to keep the image in frame after applying preferredTransform and rotations, which is commonly handled by concatenating a corrective translation [9].  
- Ensure transforms are applied to the composition’s track-specific layer instruction (not the original asset track) and avoid passthrough presets during export, which ignore videoCompositions and can make transforms appear to have no effect [10][11].
