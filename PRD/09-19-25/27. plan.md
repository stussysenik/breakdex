## Diagnosis: The Root Cause is a Timeline Mismatch

The `VideoTransformBuilder` is correctly doing two things:

1.  It creates a trimmed `AVMutableComposition` that has a short duration (e.g., 3 seconds).
2.  It uses `AVMutableVideoComposition(propertiesOf:)` to let `AVFoundation` generate the instructions needed to display that video.

The critical failure is that `AVFoundation`, by default, creates instructions whose `timeRange` matches the *original, untrimmed* video (e.g., 5.5 seconds).

The result is an invalid state: we have a 3-second movie timeline (`AVMutableComposition`) but a 5.5-second set of drawing instructions (`AVMutableVideoCompositionInstruction`). `AVFoundation` cannot resolve this conflict, so the `AVPlayerItem` never becomes ready, and our readiness check correctly times out. This affects **both rotated and non-rotated previews**.

## The Definitive Fix: Spec-Kit

The entire fix is consolidated within the `VideoTransformBuilder`. By correcting the instruction timelines, we will produce a valid composition that becomes ready to play instantly.

**File to Modify**: `VideoTransformBuilder.swift`

**Target Method**: `build(asset:trimRange:quarterTurns:)`

**Instructions**: Replace the entire `build` method with this final, corrected version. It includes the crucial timeline synchronization loop.

```swift
static func build(asset: AVAsset, trimRange: CMTimeRange? = nil, quarterTurns: Int) async throws -> (composition: AVMutableComposition, videoComposition: AVMutableVideoComposition) {
    let composition = AVMutableComposition()

    // 1. Create the trimmed composition. Its `timeRange` is now our source of truth.
    let timeRange: CMTimeRange
    if let trimRange = trimRange {
        timeRange = trimRange
    } else {
        let duration = try await asset.load(.duration)
        timeRange = CMTimeRange(start: .zero, duration: duration)
    }
    try await composition.insertTimeRange(timeRange, of: asset, at: .zero)

    // 2. Let AVFoundation create a base video composition.
    let videoComposition = AVMutableVideoComposition(propertiesOf: composition)
    
    // 3. --- THE DEFINITIVE FIX ---
    // Synchronize the instruction's timeline with the trimmed composition's timeline.
    // This is the critical step that was missing.
    if let instruction = videoComposition.instructions.first as? AVMutableVideoCompositionInstruction {
        instruction.timeRange = timeRange
    }
    
    // 4. If rotation is needed, apply it on top of the now-correct base composition.
    if quarterTurns % 4 != 0 {
        // Update render size for vertical orientations
        let originalSize = videoComposition.renderSize
        var newRenderSize = originalSize
        
        let userRotation = CGAffineTransform(rotationAngle: .pi / 2 * CGFloat(quarterTurns))
        var translation: CGAffineTransform
        
        switch quarterTurns {
        case 1: // 90°
            newRenderSize = CGSize(width: originalSize.height, height: originalSize.width)
            translation = CGAffineTransform(translationX: originalSize.height, y: 0)
        case 2: // 180°
            translation = CGAffineTransform(translationX: originalSize.width, y: originalSize.height)
        case 3: // 270°
            newRenderSize = CGSize(width: originalSize.height, height: originalSize.width)
            translation = CGAffineTransform(translationX: 0, y: originalSize.width)
        default:
            translation = .identity
        }
        videoComposition.renderSize = newRenderSize
        
        // Apply the transforms to the first (and only) layer instruction
        if let instruction = videoComposition.instructions.first as? AVMutableVideoCompositionInstruction,
           let layerInstruction = instruction.layerInstructions.first as? AVMutableVideoCompositionLayerInstruction,
           let assetTrack = composition.tracks(withMediaType: .video).first {
            
            var originalTransform: CGAffineTransform = .identity
            if layerInstruction.getTransformRamp(for: assetTrack, at: instruction.timeRange.start, start: &originalTransform, end: nil) {
                let finalTransform = originalTransform.concatenating(userRotation).concatenating(translation)
                layerInstruction.setTransform(finalTransform, for: assetTrack)
            }
        }
    }
    
    return (composition, videoComposition)
}
```
