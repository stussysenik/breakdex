## Diagnosis: Rotation Without Translation

The logs show we've made incredible progress. The `VideoTransformBuilder` is now correctly:

1.  Using the framework-native `AVMutableVideoComposition(propertiesOf:)` initializer.
2.  Updating the `renderSize` for portrait rotations (e.g., 1604x902 -\> 902x1604).
3.  Retrieving the base transform from the layer instruction provided by `AVFoundation`.

The final, critical error is revealed in this log line:
`🎬 VideoTransformBuilder: Final transform details - tx: 0.0, ty: 0.0, angle: 1.57...`

This shows we are applying a **rotation** (`angle: 1.57` which is 90°) but **zero translation** (`tx: 0.0, ty: 0.0`).

When you rotate a video frame around its origin (the top-left corner), it swings out of the visible canvas. A corresponding translation is **required** to move it back into the center of the new, correctly-sized frame. Without this translation, we are correctly rotating a video completely off-screen, resulting in a blank composition that never becomes ready to play.

**Analogy**: We are successfully turning a rectangular painting sideways to hang it on a tall, narrow wall. We've correctly identified the wall space, but we're hammering the nail into the top-left corner of the wall instead of the center. The painting is correctly rotated but hanging almost entirely off the wall, out of sight.

## The Solution: Reintroduce the Correct Translation

The definitive fix is to calculate and apply the correct `CGAffineTransform` for translation *after* applying the rotation. This will perfectly center the rotated video on its new canvas.

This solution is robust and works from first principles, combining the framework's power with the precise mathematical adjustments needed for our specific transformation.

```swift
static func build(asset: AVAsset, trimRange: CMTimeRange? = nil, quarterTurns: Int) async throws -> (composition: AVMutableComposition, videoComposition: AVMutableVideoComposition) {
    let composition = AVMutableComposition()

    let timeRange: CMTimeRange
    if let trimRange = trimRange {
        timeRange = trimRange
    } else {
        let duration = try await asset.load(.duration)
        timeRange = CMTimeRange(start: .zero, duration: duration)
    }
    try await composition.insertTimeRange(timeRange, of: asset, at: .zero)

    let videoComposition = AVMutableVideoComposition(propertiesOf: composition)
    
    // If no rotation is needed, we are done.
    if quarterTurns % 4 == 0 {
        return (composition, videoComposition)
    }
    
    // --- START: THE DEFINITIVE FIX ---
    
    let originalSize = videoComposition.renderSize
    var newRenderSize = originalSize
    
    // 1. Calculate the user rotation and the necessary translation.
    let userRotation = CGAffineTransform(rotationAngle: .pi / 2 * CGFloat(quarterTurns))
    var translation: CGAffineTransform
    
    switch quarterTurns {
    case 1: // 90°
        newRenderSize = CGSize(width: originalSize.height, height: originalSize.width)
        translation = CGAffineTransform(translationX: originalSize.height, y: 0)
    case 2: // 180°
        translation = CGAffineTransform(translationX: originalSize.width, y: originalSize.height)
    case 3: // 270°
        newRenderSize = CGSize(width: originalSize.height, height: originalSize.width)
        translation = CGAffineTransform(translationX: 0, y: originalSize.width)
    default:
        translation = .identity
    }
    videoComposition.renderSize = newRenderSize
    
    // 2. Apply the transforms in the correct order.
    for instruction in videoComposition.instructions {
        guard let layerInstruction = instruction as? AVMutableVideoCompositionInstruction,
              let assetTrack = composition.tracks(withMediaType: .video).first else { continue }
        
        var originalTransform: CGAffineTransform = .identity
        if layerInstruction.getTransformRamp(for: assetTrack, at: instruction.timeRange.start, start: &originalTransform, end: nil) {
            // Correct order: Original -> User Rotation -> Translation
            let finalTransform = originalTransform.concatenating(userRotation).concatenating(translation)
            layerInstruction.setTransform(finalTransform, for: assetTrack)
        }
    }
    
    // --- END: THE DEFINITIVE FIX ---
    
    return (composition, videoComposition)
}
```
