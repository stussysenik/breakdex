### \#\# The Core Issue: A Deadlock in Video Loading

The problem lies exclusively within the `loadVideo(from:)` function in **AddMoveViewModel.swift**.

You are correctly loading the `AVAsset`, but then you attempt to wait for the `AVPlayerItem`'s status to change *in isolation*. An `AVPlayerItem`'s status only transitions from `.unknown` to `.readyToPlay` when an `AVPlayer` instance begins to process it.

Here is the **incorrect sequence** currently in your code (`AddMoveViewModel.swift`, lines 316-334):

1.  `let playerItem = AVPlayerItem(asset: asset)`: A player item is created. Its status is `.unknown`.
2.  `try await waitForPlayerItemReady(playerItem)`: The code **hangs here**. It's waiting for `playerItem.status` to change, but nothing is triggering that change.
3.  `let player = AVPlayer(playerItem: playerItem)`: This line is **never reached**. This is the line that *would have* triggered the status change.
