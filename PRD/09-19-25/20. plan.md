## Diagnosis: The Root Cause is an Incorrect Transform Source

We correctly use `AVMutableVideoComposition(propertiesOf: composition)` to let `AVFoundation` create a valid baseline composition. This automatically creates layer instructions with the correct transforms to orient the video.

However, a few lines later, the code **discards this correct transform** and re-loads the old `preferredTransform` directly from the original asset:
`let originalTransform = try await asset.load(.preferredTransform)`

This single line re-introduces the coordinate space conflict we were trying to solve. We must use the transform that `AVFoundation` has already calculated for us *within the context of the composition*.

## The Solution: A Simple, First-Principles Fix

The solution is to retrieve the transform directly from the `AVMutableVideoCompositionLayerInstruction` that the framework prepared for us. We then apply our user's rotation on top of this correct base transform. This works *with* the framework's logic instead of fighting it, resulting in a valid composition.

This approach is:

  * **Simple**: It's a small logical change that greatly simplifies the transform math.
  * **Reliable**: It correctly handles any video, regardless of its source orientation, because it relies on `AVFoundation`'s own interpretation of the asset.
  * **Performant**: It avoids an unnecessary `async` call to `asset.load(.preferredTransform)`.

    mutableLayerInstruction.setTransform(finalTransform, for: assetTrack)

***Note on the `setTransform` method***: It is better practice to use `setTransform(_:for:)` as it associates the transform with a specific track within the composition.

### **3. Final, Corrected `build` Method**

For absolute clarity, here is the complete, corrected `build` method. Replace the existing method with this one.

```swift
static func build(asset: AVAsset, trimRange: CMTimeRange? = nil, quarterTurns: Int) async throws -> (composition: AVMutableComposition, videoComposition: AVMutableVideoComposition) {
    let composition = AVMutableComposition()

    // 1. Set the time range for the new composition based on the trim.
    let timeRange: CMTimeRange
    if let trimRange = trimRange {
        timeRange = trimRange
    } else {
        let duration = try await asset.load(.duration)
        timeRange = CMTimeRange(start: .zero, duration: duration)
    }
    try await composition.insertTimeRange(timeRange, of: asset, at: .zero)

    // 2. Let AVFoundation create a video composition that correctly handles the asset's
    // initial orientation, render size, and instructions.
    let videoComposition = AVMutableVideoComposition(propertiesOf: composition)
    
    // 3. If no rotation is needed, we are done. Return the valid composition.
    if quarterTurns == 0 {
        return (composition, videoComposition)
    }
    
    // 4. If rotation is needed, modify the composition AVFoundation made for us.
    
    // 4a. Update the render size for vertical orientations.
    let originalSize = videoComposition.renderSize
    if quarterTurns == 1 || quarterTurns == 3 {
        videoComposition.renderSize = CGSize(width: originalSize.height, height: originalSize.width)
    }

    // 4b. Create a simple transform for the user's rotation.
    let userRotation = CGAffineTransform(rotationAngle: .pi / 2 * CGFloat(quarterTurns))
    
    // 4c. Apply the user rotation on top of the existing, correct transforms.
    for instruction in videoComposition.instructions {
        guard let layerInstruction = instruction as? AVMutableVideoCompositionInstruction,
              let assetTrack = composition.tracks(withMediaType: .video).first else { continue }
        
        var originalTransform: CGAffineTransform = .identity
        if layerInstruction.getTransformRamp(for: assetTrack, at: instruction.timeRange.start, start: &originalTransform, end: nil) {
            let finalTransform = originalTransform.concatenating(userRotation)
            layerInstruction.setTransform(finalTransform, for: assetTrack)
        }
    }
    
    return (composition, videoComposition)
}
```
