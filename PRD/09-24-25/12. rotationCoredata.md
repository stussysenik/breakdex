### Minimal code outline
- Pipeline overview: export the rotated clip to a temporary file using AVAssetExportSession with a videoComposition that applies the rotation transform, then wrap PHAssetCreationRequest.creationRequestForAssetFromVideo(atFileURL:) in PHPhotoLibrary.performChanges and optionally add the created asset to a target PHAssetCollection. [1][2][3][4]

```swift
// 1) Build composition + rotation
let asset = AVURLAsset(url: sourceURL)
let composition = AVMutableComposition()
let videoTrack = asset.tracks(withMediaType: .video).first!
let compTrack = composition.addMutableTrack(withMediaType: .video,
                                            preferredTrackID: kCMPersistentTrackID_Invalid)
try? compTrack?.insertTimeRange(CMTimeRange(start: .zero, duration: asset.duration),
                                of: videoTrack,
                                at: .zero)

// Apply rotation via videoComposition
let instruction = AVMutableVideoCompositionInstruction()
instruction.timeRange = CMTimeRange(start: .zero, duration: asset.duration)

let layer = AVMutableVideoCompositionLayerInstruction(assetTrack: compTrack!)
let rotation = CGAffineTransform(rotationAngle: .pi / 2) // example 90°
let translate = CGAffineTransform(translationX: videoTrack.naturalSize.height, y: 0)
layer.setTransform(rotation.concatenating(translate), at: .zero)

instruction.layerInstructions = [layer]
let videoComp = AVMutableVideoComposition()
videoComp.instructions = [instruction]
videoComp.renderSize = CGSize(width: videoTrack.naturalSize.height,
                              height: videoTrack.naturalSize.width)
videoComp.frameDuration = CMTimeMake(value: 1, timescale: 30)

// 2) Export to file (avoid .passthrough so transforms apply)
let exporter = AVAssetExportSession(asset: composition, presetName: AVAssetExportPresetHighestQuality)!
exporter.videoComposition = videoComp
exporter.outputURL = tempURL
exporter.outputFileType = .mp4
exporter.exportAsynchronously {
  guard exporter.status == .completed else { return }

  // 3) Save to Photos and add to album
  PHPhotoLibrary.shared().performChanges({
    let creation = PHAssetChangeRequest.creationRequestForAssetFromVideo(atFileURL: tempURL)
    let placeholder = creation?.placeholderForCreatedAsset

    if let album = targetAlbum, let id = placeholder?.localIdentifier {
      let fetch = PHAsset.fetchAssets(withLocalIdentifiers: [id], options: nil)
      if let asset = fetch.firstObject, let change = PHAssetCollectionChangeRequest(for: album) {
        change.addAssets([asset] as NSFastEnumeration)
      }
    }
  }, completionHandler: { success, error in
    // handle result
  })
}
```

### Permissions and limited library
- For save‑only workflows, request authorization with PHAccessLevel.addOnly to allow adding new assets without reading existing ones, and query authorizationStatus(for:) with the same access level. [5][10]
- For users granting limited photo access, follow the WWDC guidance to present the limited library picker when needed and respect the limited state in flows that require reading existing assets or choosing an album. [6]

### Notes and gotchas
- Rotation via transforms should be applied with AVMutableVideoCompositionLayerInstruction.setTransform or by setting preferredTransform on the composition track, per Apple’s QA guidance. [1]
- If using AVAssetExportPresetPassthrough, rotation instructions are ignored, so pick a non-passthrough preset (e.g., HighestQuality) to bake in the orientation. [7]
- Album operations must occur inside performChanges; create or fetch the PHAssetCollection, then use PHAssetCollectionChangeRequest to add the new asset by its placeholder identifier. [3][4]
