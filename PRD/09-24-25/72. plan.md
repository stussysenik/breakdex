## Issue 1: Duplicate Videos Created During Save

    ```swift
    func saveToPhotosLibrary(_ asset: AVAsset) async throws -> String {
        logger.info("💾 Saving video to Photos library and BreakDex album...", metadata: nil)

        let status = await PHPhotoLibrary.requestAuthorization(for: .addOnly)
        guard status == .authorized || status == .limited else {
            let error = VideoProcessingError.photosPermissionDenied
            logger.error("❌ Photos library access denied.", metadata: nil)
            throw error
        }

        // Export the video to a temporary URL first
        let tempURL = FileManager.default.temporaryDirectory
            .appendingPathComponent(UUID().uuidString)
            .appendingPathExtension("mov")
        
        guard let exportSession = AVAssetExportSession(asset: asset, presetName: AVAssetExportPresetHighestQuality) else {
            throw VideoProcessingError.assetCreationFailed
        }
        exportSession.outputURL = tempURL
        exportSession.outputFileType = .mov
        
        await exportSession.export()

        if let error = exportSession.error {
            logger.error("❌ Video export to temporary file failed: \(error.localizedDescription)", metadata: nil)
            throw VideoProcessingError.videoProcessingFailed(operation: "exporting for photos save", underlyingError: error)
        }
        
        // Find or create the "BreakDex" album
        let album = try await breakDexAlbumManager.findOrCreateAlbum()

        // Atomically save the video and add it to the album
        return try await withCheckedThrowingContinuation { continuation in
            var placeholder: PHObjectPlaceholder?

            PHPhotoLibrary.shared().performChanges({
                // 1. Create the asset creation request from the temporary file.
                guard let assetRequest = PHAssetChangeRequest.creationRequestForAssetFromVideo(atFileURL: tempURL) else {
                    return
                }
                placeholder = assetRequest.placeholderForCreatedAsset
                
                // 2. Create the album change request.
                guard let albumChangeRequest = PHAssetCollectionChangeRequest(for: album),
                      let assetPlaceholder = placeholder else {
                    return
                }

                // 3. Add the new asset placeholder to the album change request.
                albumChangeRequest.addAssets([assetPlaceholder] as NSArray)

            }) { success, error in
                // Clean up the temporary file regardless of outcome
                try? FileManager.default.removeItem(at: tempURL)

                if success, let localIdentifier = placeholder?.localIdentifier {
                    self.logger.info("✅ Video saved to Photos and added to BreakDex album successfully.", metadata: [
                        "identifier": localIdentifier
                    ])
                    continuation.resume(returning: localIdentifier)
                } else {
                    let saveError = error ?? NSError(domain: "Photos", code: -1, userInfo: [NSLocalizedDescriptionKey: "Unknown error saving to Photos."])
                    self.logger.error("❌ Failed to save video to Photos library: \(saveError.localizedDescription)", metadata: nil)
                    continuation.resume(throwing: VideoProcessingError.photosSaveFailed(underlyingError: saveError))
                }
            }
        }
    }
    ```

# Spec: Deterministic Arsenal Video Display v1.0

## 1\. Overview

This specification details the work required to ensure that video moves saved to Core Data are fetched and displayed correctly in the "Arsenal" UI. The primary directive is to **complete the WYSIWYG loop**: the asset displayed in the Arsenal must be an exact, deterministic representation of the asset configured and saved by the user, including all trim and rotation transformations.

## 2\. "What" & "Why": Core Intent

### 2.1. Goal 🎯

To provide the user with a reliable and accurate view of their saved moves. When a user navigates to the Arsenal, they must see their video flashcards exactly as they created them. This functionality is the payoff for the entire "Add Move" flow and is critical for the app's core purpose of review and practice.

### 2.2. Non-Goals 🚫

  * **Search and Filtering:** Implementing search, tag-based filtering, or sorting in the Arsenal is out of scope.
  * **Arsenal UI/UX Redesign:** We will work within the existing UI components (`MoveListView`, `AvailableMoveRowView`, etc.) without altering their visual design.

### 2.3. User Persona & Journey 🕺

  * **Persona:** Alex, the dancer from the previous spec.
  * **Journey:**
    1.  Yesterday, Alex successfully saved his "Windmill Flare" move. It was a 4-second clip, rotated 90 degrees.
    2.  Today, he opens BreakingFlashcards and navigates to the "Arsenal" tab to review his moves.
    3.  He scrolls to "Windmill Flare" in the move list.
    4.  **Desired Outcome:** The video thumbnail and player for "Windmill Flare" show the clip in the correct 90-degree rotation. When he taps to play it, it plays only the precise 4-second trimmed portion, looping seamlessly. The experience is identical to the final preview he saw before saving.

## 3\. Verifiable Requirements

### 3.1. Functional Requirements (FR)

  * **FR1: Correct Asset Retrieval:** For each `Move` entity displayed, the system **must** use the stored `photosIdentifier` to fetch the corresponding `PHAsset` from the device's Photos library.
  * **FR2: Playback Transformation Application:** The fetched video **must not** be played in its original state. Instead, a new `AVPlayerItem` **must** be dynamically composed using the `trimStartTime`, `trimEndTime`, and `rotationQuarterTurns` metadata stored in the `Move` entity.
  * **FR3: On-Demand Loading:** Video assets **must** be loaded asynchronously and on-demand as they become visible in the list. Loading all videos at once is prohibited to conserve memory and ensure smooth scrolling.
  * **FR4: Graceful Error State:** If the `photosIdentifier` for a `Move` entity is invalid or the underlying `PHAsset` has been deleted from the Photos library, the UI **must** display a clear visual indicator (e.g., a "Video Not Found" placeholder) for that move instead of crashing or showing an empty space.

### 3.2. Non-Functional Requirements (NFR)

  * **NFR1: Performance:** The time from a move's row appearing on screen to its video thumbnail/first frame being rendered should be **\< 1.5 seconds** on a standard network connection. UI scrolling must remain fluid (≥ 55 FPS).
  * **NFR2: Resource Management:** The system must efficiently manage `AVPlayer` instances. Players for off-screen rows should be de-allocated to release memory. There should not be an unbounded number of active player instances.

### 3.3. Acceptance Criteria (AC)

  * **AC1 (WYSIWYG Playback):**

      * **Given** a move was saved with a trim from 1.3s to 5.5s and rotated 90 degrees.
      * **When** I scroll to that move in the `MoveListView`.
      * **Then** the video player for that row displays a 90-degree rotated video.
      * **And** playing the video shows only the content between 1.3s and 5.5s of the original asset.

  * **AC2 (Missing Asset):**

      * **Given** a move exists in Core Data, but its corresponding video has been deleted from the Photos app.
      * **When** I view the `MoveListView`.
      * **Then** the row for that move displays a placeholder image with a "broken link" icon instead of a video player.
      * **And** the application does not crash.

### ✅ Step 1: Create a Playback Composition Service

**Analysis:** The existing `VideoTransformBuilder` is designed for exporting files. We need a lighter-weight service focused solely on creating `AVPlayerItem` instances for in-app playback, which is a distinct concern.

1.  **Create a new file for the `PlaybackCompositionService`.**
      * **File:** `Video/PlaybackCompositionService.swift`
      * **Content:**
        ```swift
        import AVFoundation
        import Photos

        // This service is the inverse of the export builder; it reconstructs the
        // viewable state from the persisted metadata.
        struct PlaybackCompositionService {
            static func composePlayerItem(
                for asset: PHAsset,
                trimStartTime: Double,
                trimEndTime: Double,
                rotation: Int // Stored as Int16, but use Int for the function
            ) async throws -> AVPlayerItem {

                let options = PHVideoRequestOptions()
                options.version = .current
                options.deliveryMode = .automatic

                guard let avAsset = await requestAVAsset(for: asset, options: options) else {
                    throw NSError(domain: "PlaybackCompositionService", code: 1, userInfo: [NSLocalizedDescriptionKey: "Could not retrieve AVAsset from PHAsset."])
                }

                // If no transformations are needed, return a simple player item.
                if trimStartTime == 0 && trimEndTime >= avAsset.duration.seconds && rotation == 0 {
                    return AVPlayerItem(asset: avAsset)
                }
                
                // Use the same composition logic as the save/preview flow to ensure consistency.
                let composition = AVMutableComposition()
                let timeRange = CMTimeRange(
                    start: CMTime(seconds: trimStartTime, preferredTimescale: 600),
                    end: CMTime(seconds: trimEndTime, preferredTimescale: 600)
                )

                if let videoTrack = try await avAsset.loadTracks(withMediaType: .video).first {
                    let compositionVideoTrack = composition.addMutableTrack(withMediaType: .video, preferredTrackID: kCMPersistentTrackID_Invalid)
                    try? compositionVideoTrack?.insertTimeRange(timeRange, of: videoTrack, at: .zero)
                }

                if let audioTrack = try await avAsset.loadTracks(withMediaType: .audio).first {
                    let compositionAudioTrack = composition.addMutableTrack(withMediaType: .audio, preferredTrackID: kCMPersistentTrackID_Invalid)
                    try? compositionAudioTrack?.insertTimeRange(timeRange, of: audioTrack, at: .zero)
                }
                
                let playerItem = AVPlayerItem(asset: composition)

                if rotation != 0 {
                    let videoComposition = VideoTransformBuilder.buildVideoComposition(
                        for: composition,
                        asset: avAsset,
                        quarterTurns: rotation
                    )
                    playerItem.videoComposition = videoComposition
                }

                return playerItem
            }

            private static func requestAVAsset(for asset: PHAsset, options: PHVideoRequestOptions) async -> AVAsset? {
                await PHImageManager.default().requestAVAsset(forVideo: asset, options: options)
            }
        }

        // Helper extension to make PHImageManager async
        extension PHImageManager {
            func requestAVAsset(forVideo asset: PHAsset, options: PHVideoRequestOptions?) async -> AVAsset? {
                return await withCheckedContinuation { continuation in
                    self.requestAVAsset(forVideo: asset, options: options) { avAsset, _, _ in
                        continuation.resume(returning: avAsset)
                    }
                }
            }
        }
        ```

### ✅ Step 2: Create a Row-Specific ViewModel

        ```swift
        import SwiftUI
        import AVFoundation
        import Photos
        import OSLog

        @MainActor
        class MoveRowViewModel: ObservableObject {
            enum State {
                case idle
                case loading
                case ready(AVPlayer)
                case error(String)
            }

            @Published private(set) var state: State = .idle
            let move: Move
            private let logger = Logger(subsystem: "com.breakingflashcards", category: "MoveRowViewModel")

            init(move: Move) {
                self.move = move
            }

            func loadVideo() async {
                guard case .idle = state else { return } // Load only once

                state = .loading
                logger.info("🎬 Loading video for move: '\(self.move.name ?? "Untitled")'")

                do {
                    guard let identifier = move.photosIdentifier else {
                        throw NSError(domain: "MoveRowViewModel", code: 2, userInfo: [NSLocalizedDescriptionKey: "Missing Photos Identifier"])
                    }
                    
                    let fetchResult = PHAsset.fetchAssets(withLocalIdentifiers: [identifier], options: nil)
                    guard let phAsset = fetchResult.firstObject else {
                        throw NSError(domain: "MoveRowViewModel", code: 3, userInfo: [NSLocalizedDescriptionKey: "Video not found in Photos."])
                    }

                    let playerItem = try await PlaybackCompositionService.composePlayerItem(
                        for: phAsset,
                        trimStartTime: move.trimStartTime,
                        trimEndTime: move.trimEndTime,
                        rotation: Int(move.rotationQuarterTurns)
                    )

                    let player = AVPlayer(playerItem: playerItem)
                    player.actionAtItemEnd = .none // Enable looping
                    
                    state = .ready(player)
                    logger.info("✅ Video ready for move: '\(self.move.name ?? "Untitled")'")
                } catch {
                    state = .error(error.localizedDescription)
                    logger.error("❌ Failed to load video for move '\(self.move.name ?? "Untitled")': \(error.localizedDescription)")
                }
            }
        }
        ```
