## The Root Cause: Type Ambiguity

The error "Type of expression is ambiguous without a type annotation" is appearing in your `timeCodeDisplay` and `controlSection` computed properties. This happens because the combination of nested views (like `HStack`, `VStack`, `Button`) and chained modifiers (like `.onAppear` and `.overlay`) makes it difficult for the Swift compiler to determine the exact, final type of the view being returned.

## The Solution: How to Fix It

The solution is to wrap the content of each problematic computed property in a `Group`. A `Group` acts as a transparent container that doesn't affect your UI layout but provides a single, unambiguous root for the view hierarchy, resolving the compiler's confusion.
