This error means a SwiftUI Binding is being treated like a callable function (something with parentheses) rather than a property wrapper for state.  
Do not add parentheses to a Binding; pass the Binding where an API expects a Binding, and pass binding.wrappedValue where an API expects the underlying value.  
To mutate a Binding, write binding.wrappedValue = newValue or binding.wrappedValue.toggle() for a Bool, instead of calling the Binding as if it were a function.  
For list edits, perform mutations on the actual collection (array) and attach onDelete/onMove to the ForEach, not the List, and never call methods on a binding to an object (use store.items.move(...) rather than $store.move(...)).  
If an API needs a non-optional but the model exposes Binding<Value?>, bridge it with Binding(get:set:) to provide a default value and write-through safely.  
When in doubt, break expressions into intermediate lets with explicit types to make clear whether a Binding or a plain value is required and remove accidental “calls.”
