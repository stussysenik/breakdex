## 1\. Root Cause Analysis

### Rotation Cropping: A Non-Commutative Transform Composition

The system can be modeled as a chain of morphisms (function calls) acting on data objects (`AVAsset`). The rotation failure occurs within the `VideoTransformBuilder` object, as revealed by the logs.

  * **Objects:** `FeatureRichTrimmerView` (UI), `AddMoveUnifiedState` (State), `TrimmerViewModel` (State), `VideoTransformBuilder` (Processor), `AVAsset` (Data).
  * **Morphism Chain:** A user tap on "Rotate" triggers `applyTrimSettings`, which eventually calls `VideoTransformBuilder.createPlayerItem`. This final morphism is where the error occurs.

The logs provide the smoking gun:

```log
🎬 BUILDER:   - Original size: 1920.0x1080.0
🎬 BUILDER:   - Rotated size: 1080.0x1920.0
🎬 VideoTransformBuilder: - Final combined transform: CGAffineTransform(a: -1.0, b: ..., c: ..., d: -1.0, tx: 1080.0, ty: 1080.0)
```

This "Final combined transform" is fundamentally incorrect for a 90-degree rotation. A transform matrix with `a: -1.0` and `d: -1.0` represents a **180-degree rotation (a flip)**. The correct 90-degree rotation matrix involves swapping and negating coefficients (e.g., `a: 0, b: 1, c: -1, d: 0`).

This is a **non-commutative diagram failure**. The builder is likely composing the asset's `preferredTransform` with a new rotation transform in the wrong order or with incorrect calculations. The translation `(tx: 1080.0, ty: 1080.0)` is also wrong; for a landscape-to-portrait rotation, the `ty` should be `0`, not `1080`. This incorrect translation is what causes the final video to be offset and cropped into a square.

### Large Video Loading UX: Missing State Representation

The current loading view is driven by a progress percentage and a status string. For long operations, this is insufficient. This is an "object gap" in our state model; the `AddMoveUnifiedState` object lacks a representation for elapsed time during the loading phase. The solution is to introduce a new morphism (a timer) to update this new state property, mirroring the existing implementation for the save operation.

class VideoTransformBuilder {

    /// Creates a video composition with correct rotation and trimming.
    /// This is the "Natural Transformation" that fixes the buggy functor.
    static func buildComposition(
        for asset: AVAsset,
        trimRange: CMTimeRange,
        quarterTurns: Int
    ) async throws -> (AVPlayerItem, AVMutableVideoComposition) {

        // 1. Load essential video track properties
        guard let videoTrack = try await asset.loadTracks(withMediaType: .video).first else {
            throw NSError(domain: "VideoTransformBuilder", code: 1, userInfo: [NSLocalizedDescriptionKey: "No video track found"])
        }
        
        let naturalSize = try await videoTrack.load(.naturalSize)
        let preferredTransform = try await videoTrack.load(.preferredTransform)
        
        // 2. Create the main composition and tracks
        let composition = AVMutableComposition()
        guard let compositionVideoTrack = composition.addMutableTrack(withMediaType: .video, preferredTrackID: kCMPersistentTrackID_Invalid),
              let compositionAudioTrack = composition.addMutableTrack(withMediaType: .audio, preferredTrackID: kCMPersistentTrackID_Invalid) else {
            throw NSError(domain: "VideoTransformBuilder", code: 2, userInfo: [NSLocalizedDescriptionKey: "Could not create composition tracks"])
        }
        
        // Insert the trimmed time range
        try compositionVideoTrack.insertTimeRange(trimRange, of: videoTrack, at: .zero)
        
        // Insert audio track if available
        if let audioTrack = try await asset.loadTracks(withMediaType: .audio).first {
            try compositionAudioTrack.insertTimeRange(trimRange, of: audioTrack, at: .zero)
        }
        
        // 3. ✨ CORRECTLY Calculate Render Size and Transform
        let rotationAngle = .pi / 2.0 * Double(quarterTurns)
        var finalTransform = preferredTransform.concatenating(CGAffineTransform(rotationAngle: rotationAngle))

        // Determine the video's orientation after its preferred transform is applied
        let transformedSize = naturalSize.applying(preferredTransform)
        let isPortraitAfterPreferred = abs(transformedSize.width) < abs(transformedSize.height)

        var renderSize: CGSize
        
        // If we rotate an odd number of times (90, 270), the width and height swap.
        if quarterTurns % 2 != 0 {
            renderSize = CGSize(width: naturalSize.height, height: naturalSize.width)
            
            // This is the key fix for the translation that causes the crop
            if isPortraitAfterPreferred {
                 // The video was originally portrait (e.g. iPhone recording)
                 // After a 90-degree turn, it becomes landscape.
                 // We need to adjust the transform to fit the new render size.
                 switch quarterTurns {
                 case 1: // 90 degrees
                     finalTransform = finalTransform.concatenating(CGAffineTransform(translationX: naturalSize.height, y: 0))
                 case 3: // 270 degrees
                     finalTransform = finalTransform.concatenating(CGAffineTransform(translationX: 0, y: naturalSize.width))
                 default: break
                 }
            } else {
                 // The video was originally landscape.
                 // After a 90-degree turn, it becomes portrait.
                 switch quarterTurns {
                 case 1: // 90 degrees
                     finalTransform = finalTransform.concatenating(CGAffineTransform(translationX: naturalSize.height, y: 0))
                 case 3: // 270 degrees
                     finalTransform = finalTransform.concatenating(CGAffineTransform(translationX: 0, y: naturalSize.width))
                 default: break
                 }
            }
        } else {
            // For 0 or 180-degree rotations, size remains the same but transform needs adjustment.
            renderSize = naturalSize
            if quarterTurns == 2 { // 180 degrees
                finalTransform = finalTransform.concatenating(CGAffineTransform(translationX: naturalSize.width, y: naturalSize.height))
            }
        }

        // 4. Create composition instructions
        let instruction = AVMutableVideoCompositionInstruction()
        instruction.timeRange = CMTimeRange(start: .zero, duration: trimRange.duration)
        
        let layerInstruction = AVMutableVideoCompositionLayerInstruction(assetTrack: compositionVideoTrack)
        layerInstruction.setTransform(finalTransform, at: .zero)
        
        instruction.layerInstructions = [layerInstruction]
        
        // 5. Create the final video composition
        let videoComposition = AVMutableVideoComposition()
        videoComposition.renderSize = renderSize
        videoComposition.instructions = [instruction]
        videoComposition.frameDuration = CMTime(value: 1, timescale: 30) // Standard 30fps
        
        // 6. Create the player item
        let playerItem = AVPlayerItem(asset: composition)
        playerItem.videoComposition = videoComposition
        
        return (playerItem, videoComposition)
    }
