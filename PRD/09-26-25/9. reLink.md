# Future Re-link Functionality:
The architecture of storing the localIdentifier in CoreData is the perfect foundation for this feature. The implementation would involve:
- A "Re-link" button in MoveDetailView.
- On tap, use PHAsset.fetchAssets(withLocalIdentifiers:options:) with the stored identifier.

If the asset is not found (user deleted it), prompt the user to select a new video or delete the CoreData entry.
