A cleaner, more minimal look comes from using a single accent color for the selected range on a neutral track, plus pill-shaped end handles with adequate hit targets and contrast for accessibility. [1][2][3][4] Unify semantics so color isn’t the only signal for start vs. end, relying instead on shape and label placement to stay minimal yet unambiguous. [5][1]

## Color and semantics
- Use one app accent color for the active segment and a subtle, low-contrast neutral for the unselected track to emphasize content and preserve deference. [1][2]
- Don’t rely on red vs. blue to encode begin/end; differentiate with handle shapes or inline labels so meaning isn’t conveyed by color alone. [5][1]
- Ensure the accent/track contrast meets minimum readability guidelines so controls remain legible in bright environments. [4]

## Handles and track
- Make each end handle a rounded “pill” or capsule with a visible thumb, keeping the track thin and the selected segment slightly thicker to telegraph the active range. [6][2]
- Size each interactive handle to at least 44×44 pt and give it generous padding so it’s easy to grab during precise trims. [3][7]
- Mirror the familiar Photos/iMovie affordance of draggable end caps on a filmstrip/timeline to leverage platform recognition while staying minimal. [8][9]

## Layout and spacing
- Maintain a clear hierarchy: place Start and End times close to their respective handles, and keep Duration centered beneath, using subtle weight/size to indicate importance. [2][10]
- Add roughly 12 pt of breathing room around controls to prevent accidental taps, which also keeps the minimal design feeling calm. [7][10]
- Keep alignment within the safe area and avoid crowding bottom actions to reduce visual noise. [10][2]

## Typography
- Use SF system styles for legibility and hierarchy, and prefer tabular/monospaced digits so time labels don’t jitter as values change. [11][12]
- Support Dynamic Type so labels scale cleanly without breaking the minimal layout. [11][13]

## Concrete tweak list
- Replace dual blue/red with a single accent for the active range and gray for the rest of the track. [1][5]
- Swap square ends for capsule handles; increase handle hit areas to 44×44 pt with invisible padding. [3][7]
- Thin the base track, slightly thicken the selected segment, and keep caps visually distinct but low-chrome. [6][2]
- Move Start and End timestamps closer to their handles; center Duration underneath with secondary emphasis. [2][10]
- Use monospaced digits for all mm:ss.ff labels and test contrast at 4.5:1 or better. [12][4]
- Match Photos’ drag behavior and preview while keeping styling understated to remain platform-consistent. [8][9]

struct TrimmerBar: View {
    @Binding var start: CGFloat
    @Binding var end: CGFloat
    var body: some View {
        ZStack(alignment: .leading) {
            Capsule().fill(Color.secondary.opacity(0.25)).frame(height: 4)
            Capsule().fill(.accent).frame(width: end - start, height: 6)
                .offset(x: start)
            handle.at(start)
            handle.at(end - 24)
        }
        .padding(.vertical, 12) // breathing room ~12pt
    }
    private var handle: some View {
        RoundedRectangle(cornerRadius: 8, style: .continuous)
            .fill(.background)
            .overlay(RoundedRectangle(cornerRadius: 8).stroke(.accent, lineWidth: 2))
            .frame(width: 24, height: 24) // visual
            .contentShape(Rectangle())
            .padding(10) // expands to ≥44x44 target
    }
}
