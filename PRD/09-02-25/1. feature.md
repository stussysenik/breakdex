# ELI-19 Feature Implementation Guide  
*(Engineer-oriented, but kept intuitive)*  

### 1. Layout Skeleton (SwiftUI)

- Build a root `VStack` that stretches **safe-area to safe-area**.  
- Inside, top-to-bottom:
  1. `LiveVideoPlayer`
  2. `TrimTimelineView` (your scrubbable trimmer)
  3. `PrimaryControlsBar` (`Back`, `Save Trim`)
  4. `RotateButtonBar` (single ↻ icon, right-aligned)  
- Add `.safeAreaInset(edge: .bottom) { Color.clear.frame(height:34) }` so nothing hides behind the home indicator on iPhone 13 Pro+.

### 2. Sizing Rules

| Element | Height Strategy | Key Modifiers |
|---------|-----------------|---------------|
| LiveVideoPlayer | **Flexible** – fills all leftover vertical space | `.frame(maxHeight:.infinity, alignment:.top)` |
| TrimTimelineView | Fixed ≈80 pt (fits fat thumbs, shows waveform) | `GeometryReader`→`.frame(height:80)`→`.padding(.horizontal,16)` |
| PrimaryControlsBar | 44 pt (standard touch target) | `HStack`→`.padding(.horizontal,24)` |
| RotateButtonBar | 44 pt, trailing-aligned | `HStack`→`.frame(maxWidth:.infinity, alignment:.trailing)`→`.padding(.trailing,32)` |

### 3. Rotate Logic (Quarter-turns)

```swift
@State private var rotationQuarterTurns = 0
@State private var player: AVPlayer = ...

private var angle: CGFloat { .pi / 2 * CGFloat(rotationQuarterTurns) }

func rotateVideo() {
    rotationQuarterTurns = (rotationQuarterTurns + 1) % 4           // 0,1,2,3
    let transform = CGAffineTransform(rotationAngle: angle)
    player.currentItem?.preferredTransform = transform              // preview
}
```

- Preview: apply transform to the player’s `AVPlayerLayer` or `VideoPlayer` overlay.  
- Persist: when exporting, create an `AVMutableVideoComposition` with a **single layer instruction** that sets the identical transform at `kCMTimeZero`; this avoids full re-encode.

### 4. Keep Trimmer Accurate After Rotation

- Because a 90°/270° turn swaps width↔height, update the internal geometry of `TrimTimelineView`:

```swift
.onChange(of: rotationQuarterTurns) { _ in
    timelineScale = (rotationQuarterTurns % 2 == 0) ? .horizontal : .vertical
}
```

- Drive handle positions with **time, not pixels**, so the mapping survives any dimension swap.

### 5. Spacing & Tap-Safety

- Add `Spacer(minLength:12)` (≈1 finger) between major blocks to prevent accidental cross-taps.  
- Keep interactive surfaces ≥44×44 pt.  
- Use `.contentShape(Rectangle())` on the rotate icon so the hit area is forgiving.

### 6. Export Pipeline Snippet

```swift
let asset = AVURLAsset(url: originalURL)
let comp = AVMutableComposition()
try comp.insertTimeRange(.zero..<asset.duration, of: asset, at: .zero)

let instr = AVMutableVideoCompositionLayerInstruction(assetTrack: comp.tracks[0])
instr.setTransform(asset.preferredTransform.concatenating(transform), at: .zero)

let mainInstr = AVMutableVideoCompositionInstruction()
mainInstr.timeRange = .zero..<asset.duration
mainInstr.layerInstructions = [instr]

let videoComp = AVMutableVideoComposition()
videoComp.renderSize = (rotationQuarterTurns % 2 == 0) ? asset.naturalSize
                                                       : CGSize(width:asset.naturalSize.height,
                                                                height:asset.naturalSize.width)
videoComp.instructions = [mainInstr]
videoComp.frameDuration = CMTime(value:1, timescale:30)
```

### 7. Accessibility & Feedback

- Announce “Rotated ninety degrees” via `UIAccessibility.post(notification: .announcement, ...)`.  
- Haptics: light impact on each rotate; success haptic after successful export.

### 8. Performance Tips

- Defer `AVAssetExportSession` creation until the user taps **Save Trim**.  
- Use `presetName: AVAssetExportPresetPassthrough` when only trimming/rotating; this copies streams and avoids recompression.  

### 9. Dark-Mode & Adaptive Colors

- Backgrounds: `Color(UIColor.systemBackground)`  
- Buttons: `tint(.accentColor)`; use SF Symbol “rotate.right” for consistency.

### 10. Quick QA Checklist

- ✅ Video preview fills remaining space on iPhone 13 Pro, 13 Pro Max, 14 Pro Max.  
- ✅ Trimmer remains 80 pt tall in all rotations.  
- ✅ Rotate button never collides with home indicator.  
- ✅ Exported file reflects trim **and** rotation without black bars.
