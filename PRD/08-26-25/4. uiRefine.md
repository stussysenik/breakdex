**Task 6: Ensure the "Save Combo" Button is Functional**

**File to Modify:** `CreateComboView.swift`

**Instructions:**
The "Save Combo" button's `action` must correctly call a `saveCombo()` function. This function must be implemented with the following logic:

1.  Create a new `Combo` object in the `viewContext`. Assign it a `UUID` and a name (you can prompt the user or use a default).
2.  Iterate through the `@State var comboMoves` array using `.enumerated()` to get both the `index` and the `move`.
3.  For each item, create a new `ComboMove` object.
4.  Set the `comboMove.sequenceIndex` to the `index` from the loop.
5.  Link the entities: set `comboMove.move` to the `move` from the loop, and `comboMove.combo` to the new `Combo` object you created in step 1.
6.  Wrap the save operation in a `do-catch` block. Call `try viewContext.save()`.
7.  On a successful save, immediately transition the view to a success state to provide clear feedback to the user that their action worked.
