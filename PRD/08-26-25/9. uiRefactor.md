### Agent Task: Implement a Refined, Multi-Stage Video Selection and Trimming Workflow

**Project Goal:**
Refactor the `AddMoveView` to create a more intuitive and flexible workflow for adding a new move. The user must be able to preview their selected video, have the option to re-select it, and then proceed to a trimming stage before naming and saving the final clip.

**Core Requirements:**

1.  **Implement a Multi-Stage State Machine:** The view's logic must be driven by a clear state enum that represents each step: Ready -> Loading -> Previewing -> Naming.
2.  **Enable Video Re-selection:** In the preview stage, the user must have an explicit "Change Video" option.
3.  **Integrate Native Trimming:** The trim interface should only be presented when the user explicitly chooses to edit the previewed video.
4.  **Improve UI Readability:** The final naming screen must feature a clean and readable text input field.

***

**Step-by-Step Implementation Guide:**

**1. Rearchitect the `AddMoveView` State Machine**

The key to this improved logic is a more descriptive state enum. This allows the view to gracefully transition between each step of the user's journey.

**Action:** In `AddMoveView.swift`, replace the existing `AddMoveState` enum with the following new structure.

```swift
// In AddMoveView.swift:

// 1. Replace the old state enum with this more descriptive version.
enum AddMoveState {
    case ready                                  // The initial state.
    case loading                                // Briefly shown after video selection.
    case previewing(originalURL: URL)           // User confirms the selected video.
    case naming(finalURL: URL, name: String)    // User names the trimmed/final video.
    case error(message: String)                 // Handles any failures.
}

// 2. Update the state variable.
@State private var currentState: AddMoveState = .ready

// 3. Add a new state variable to manage the text field input.
@State private var moveName: String = ""
```

private func handleVideoSelection(url: URL) {
