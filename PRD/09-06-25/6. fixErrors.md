Here is a concise spec‑kit that resolves the AVFoundation deprecations and Swift concurrency warnings shown, with replacements, migration steps, and testing/rollout guidance.[1][2][3][4][5][6][7]

## Background  
- AVAsset APIs moved to async key/value loading in iOS 16, deprecating synchronous accessors like tracks(withMediaType:), preferredTransform, and duration.[2][3][1]
- AVAssetExportSession modernized in iOS 18 with an async export(to:as:…) API and a states(updateInterval:) AsyncSequence replacing status/error polling.[4][8][5]
- AVAsset init(url:) is deprecated in iOS 18 in favor of constructing AVURLAsset directly.[6][9]
- Swift 6 strict concurrency flags non‑Sendable AVFoundation objects (e.g., AVMutableCompositionTrack) crossing isolation boundaries, requiring actor isolation or Sendable value alternatives.[10][7]

## Goals  
- Replace deprecated AVAsset property access with async loading via load(_:), and track enumeration with loadTracks(withMediaType:).[11][3][2]
- Replace AVAssetExportSession status/error polling with states(updateInterval:) and export(to:as:…) async.[5][4]
- Replace AVAsset(url:) with AVURLAsset(url:) throughout the codebase.[9][6]
- Eliminate “Non‑sendable result type … cannot be sent from nonisolated context” by confining AVFoundation objects to the main actor or by returning Sendable value types.[12][7]

## Non‑Goals  
- No changes to media features or file format support beyond API migration are planned.[8]
- No attempt to force AVFoundation reference types to conform to Sendable will be made.[7]

## Target platforms  
- Minimum iOS 16 to adopt async AVAsset loading and track APIs, with iOS 18 behavior for export and status monitoring where available.[13][4]

## API changes  
- Use AVURLAsset for URL‑backed assets.[6][9]
- Load values asynchronously: duration, preferredTransform, and other keys through load(_:).[3][2]
- Load tracks asynchronously via loadTracks(withMediaType:).[11]
- Export with export(to:as:…), and observe progress via states(updateInterval:).[4][5]

### Swift examples  
```swift
// Asset creation
let asset = AVURLAsset(url: url) // AVAsset(url:) is deprecated in iOS 18. [30][33]

// Async value loading (iOS 16+)
let duration = try await asset.load(.duration) // replaces asset.duration. [11]
let transform = try await asset.load(.preferredTransform) // replaces preferredTransform. [13]

// Async track loading (iOS 15+/16 deprecation of sync calls)
let videoTracks = try await asset.loadTracks(withMediaType: .video) // replaces tracks(withMediaType:). [6][2]

// Export (iOS 18+)
let exportSession = AVAssetExportSession(asset: asset, presetName: AVAssetExportPresetHighestQuality)! // class remains but status is deprecated. [25][21]
try await exportSession.export(to: outputURL, as: .mov) // replaces export()/exportAsynchronously. [29]
for await state in exportSession.states(updateInterval: 0.2) {
    // handle .pending/.exporting(progress)/.completed/.failed states
} // replaces polling status/progress. [21]
```

## Concurrency model  
- Mark ViewModels that create or return AVFoundation reference types as @MainActor to keep non‑Sendable objects on one actor.[14][7]
- When a Sendable boundary is required, return value‑type descriptors (IDs, time ranges, sizes) instead of AVFoundation objects.[12][7]
- Avoid sending AVMutableCompositionTrack arrays across actors; either confine to @MainActor or translate to Sendable summaries.[15][7]

### Concurrency examples  
```swift
@MainActor
final class TrimmerViewModel {
    func makeTracks(from composition: AVMutableComposition) -> [AVMutableCompositionTrack] {
        composition.tracks as? [AVMutableCompositionTrack] ?? [] // stays on MainActor. [52]
    }
}

// Sendable alternative for cross-actor communication
struct TrackDescriptor: Sendable {
    let id: CMPersistentTrackID
    let mediaType: AVMediaType
    let timeRange: CMTimeRange
} // prefer sending descriptors instead of AVFoundation objects. [52][45]
```

## Migration plan  
- Replace AVAsset(url:) with AVURLAsset(url:) and remove direct AVAsset construction.[9][6]
- Convert all synchronous AVAsset getters (duration, preferredTransform, naturalSize‑adjacent uses) to try await load(_:) calls.[2][3]
- Replace tracks(withMediaType:) with try await loadTracks(withMediaType:).[1][11]
- Migrate exporters to try await export(to:as:…) and progress observation with states(updateInterval:).[5][4]
- Annotate view‑facing models as @MainActor and refactor any cross‑actor returns of AVMutableCompositionTrack into Sendable descriptors.[10][7]

## Acceptance criteria  
- No build warnings for deprecated AVAsset or AVAssetExportSession APIs on iOS 16–18.[1][4][5]
- No Swift 6 strict concurrency warnings for “non‑Sendable … cannot be sent from nonisolated context.”[7]
- Exports succeed using export(to:as:…) and progress is observable via states(updateInterval:).[4][5]

## Test strategy  
- Unit tests for async load(.duration) and load(.preferredTransform) verifying values match known fixtures.[3][2]
- Integration tests that export several sample assets and validate success/failure via the states(updateInterval:) sequence.[4]
- Concurrency tests that call ViewModel APIs from tasks and confirm no Sendable or isolation diagnostics under “Complete” concurrency checking.[7]

## Rollout  
- Raise deployment target to iOS 16+ or compile conditionally when maintaining earlier targets.[13]
- Enable “Strict Concurrency Checking: Complete” to catch future cross‑actor violations.[7]
- Monitor crash and export telemetry during staged rollout to ensure the async exporter behaves as expected.[4]

## Risks and mitigations  
- Async loading can surface previously latent race conditions; mitigate by keeping AVFoundation usage confined to @MainActor or a dedicated actor.[7]
- Export pipeline changes may affect progress UI; mitigate by adapting UI to the states(updateInterval:) sequence semantics.[4]

| Old API | Replacement | Notes |
|---|---|---|
| AVAsset(url:) [6] | AVURLAsset(url:) [9] | Direct AVAsset init is deprecated in iOS 18. [6] |
| asset.duration [2] | try await asset.load(.duration) [2] | Requires async/await in iOS 16+. [2] |
| asset.preferredTransform [3] | try await asset.load(.preferredTransform) [3] | Async key/value loading replaces sync property. [3] |
| tracks(withMediaType:) [1] | try await loadTracks(withMediaType:) [11] | Sync enumeration deprecated in iOS 16. [11] |

## Code mods checklist  
- Replace synchronous calls and properties with load(_:)/loadTracks equivalents.[11][2][3]
- Swap all exporter invocations to export(to:as:…) and remove direct status/error reads.[5][4]
- Constrain AVFoundation objects to the main actor or convert to Sendable value types before crossing actors.[12][7]
- Replace AVAsset(url:) construction.[6]
