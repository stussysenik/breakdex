Key Flow Summary:

1. User taps "Change Video" → startVideoReplacement()
2. Show confirmation (if needed) → beginVideoReplacementProcess()
3. Process selection → processVideoReplacement() → unifiedState.replaceSelectedVideo()
4. Load new video → loadVideo(from:) → Modern video loading service
5. Create player view model → Sets currentPlayerViewModel
6. Show visual preview → TrimmerPlayerView displays the loaded video

The visual preview appears when TrimmerPlayerView detects that both isReady is true AND currentPlayerViewModel exists, at which point it renders the CustomVideoPlayerView with the loaded video content.

# I want to preserve intrinsic rotation but reset only user-applied rotation:

The most critical modification point is replaceSelectedVideo() where you set userAppliedRotation = 0 before loading the new video, ensuring the Change button loads the asset with its original orientation (0 degrees user rotation).
