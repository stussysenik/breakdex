Root Cause Found:

  The issue is in the VideoPickerWrapper at AddMoveContainer.swift:366-370. When the Pre-Trim view calls viewModel.reset(), it sets selectedItem = nil in the ViewModel, but the VideoPickerWrapper's local @State private var 
  selectedItem: PhotosPickerItem? is not synchronized with the ViewModel's selectedItem.

  The Problem:
  1. Pre-Trim back button → viewModel.reset() → clears viewModel.selectedItem ✅
  2. VideoPickerWrapper has its own @State var selectedItem that becomes nil ❌
  3. PhotosPicker binding becomes unresponsive when local state is cleared ❌

  The Fix:
  Make the VideoPickerWrapper use the ViewModel's selectedItem directly instead of maintaining local state:

  // In AddMoveContainer.swift, replace VideoPickerWrapper:
  struct VideoPickerWrapper: View {
      @ObservedObject var viewModel: AddMoveViewModel

      var body: some View {
          PhotosPicker(
              selection: $viewModel.selectedItem,  // Use ViewModel's binding directly
              matching: .videos,
              photoLibrary: .shared()
          ) {
              Text("Select Video")
                  .font(.system(size: 17, weight: .semibold))
                  .foregroundColor(.blue)
          }
          .photosPickerStyle(.inline)
          // Remove onChange - ViewModel handles selection via didSet
      }
  }
