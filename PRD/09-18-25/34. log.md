  they miss these initial updates.

  - Line 70: Monitor starts correctly
  - Line 71: Correctly waits for status update
  - Line 72: Observers set up successfully
  - Then... nothing happens - because the status change occurred before observers
  were ready

  The Fix:

  Add .initial to both observer options so they trigger when first set up, ensuring
   we catch the current state and any subsequent changes.
