### \#\# The Diagnosis: A Flawed and Fragile Handoff

The core issue is that the `finishTrimming()` method is performing an unnecessary and faulty **pre-export** of the video. Instead of just passing the *instructions* (the trim times and rotation angle) to the next view, it's trying to create a whole new video file in a temporary location.

This architectural flaw is the root cause of all your symptoms:

1.  **The Black Screen:** The log file is crystal clear. The pre-export process creates a corrupted or inaccessible temporary video file. When `NameMoveView` tries to play it, the player item reports its duration as `nan` (Not a Number), resulting in a black screen.
2.  **Uncertain Trim Range:** You're right to be uncertain. Because the asset is corrupted, there's no guarantee that the video preview, even if it did appear, would respect the trim ranges. The data is disconnected from the visual representation.
3.  **Rotation Not Showing:** Even though the correct rotation value (`3`) is passed to the `NameMoveView`, it doesn't matter because the underlying video asset is unplayable.

The principle should be: **Export only once, at the very end.** The transition between trimming and naming should be a lightweight, pure data handoff.

### \#\# The Solution: A Clean Handoff with an "In-Memory" Preview

We will fix this by eliminating the temporary export entirely. Instead, we'll use your powerful `VideoTransformBuilder` to create a perfect, **in-memory preview** for the `NameMoveView`. This guarantees that what you see is exactly what you'll save.

struct NameMoveView: View {
    @Bindable var viewModel: AddMoveViewModel
    
    // 👇 Add state to hold the player view model, which will be built asynchronously.
    @State private var playerViewModel: UnifiedVideoPlayerViewModel?
    @State private var isSaving = false

            if case .naming(_, _, _, trimStartTime, trimEndTime, _) = viewModel.state {
                // Video preview section
                VStack(spacing: 16) {
                    // 👇 Use the new playerViewModel from state
                    if let vm = playerViewModel {
                        // The rotation is now handled by the video composition inside the player item
                        CustomVideoPlayerView(viewModel: vm, rotationQuarterTurns: .constant(0))
                            .frame(height: 300)
                            .cornerRadius(12)
                            .padding(.horizontal)
                    } else {
                        // Show a loading indicator while the preview is being prepared.
                        ProgressView("Preparing Preview...")
                            .frame(height: 300)
                    }
                    
                    // Video info - use the precise formatTime function
                    Text("Trimmed: \(formatTime(trimStartTime)) - \(formatTime(trimEndTime))")
                        .font(.caption)
                        .foregroundColor(.secondary)
                    
                    // ... rest of the view ...
                }
                // ...
            }
        }
        .background(Color.black.ignoresSafeArea())
        // 👇 Use a .task modifier to build the composed player item when the view appears.
        .task(id: viewModel.state) {
            guard case .naming(_, let originalAsset, _, let trimStartTime, let trimEndTime, let rotation) = viewModel.state else { return }
            
            do {
                let timeRange = CMTimeRange(
                    start: CMTime(seconds: trimStartTime, preferredTimescale: 600),
                    end: CMTime(seconds: trimEndTime, preferredTimescale: 600)
                )

                // Use the builder to create a perfect, in-memory player item
                let composedPlayerItem = try await VideoTransformBuilder.createPlayerItem(
                    asset: originalAsset,
                    trimRange: timeRange,
                    quarterTurns: rotation
                )
                
                let player = AVPlayer(playerItem: composedPlayerItem)
                
                // Assign the fully prepared view model to the state to trigger the view update.
                self.playerViewModel = UnifiedVideoPlayerViewModel(
                    player: player,
                    mode: .preview,
                    appContainer: AppContainer.shared
                )
            } catch {
                logger.error("Failed to create composed preview player item: \(error)")
                viewModel.setErrorState(message: "Could not create video preview.")
            }
        }
    }

    // 👇 Use the precise time formatting function
    private func formatTime(_ seconds: Double?) -> String {
        guard let seconds = seconds else { return "00:00.00" }
        let minutes = Int(seconds) / 60
        let secs = seconds.truncatingRemainder(dividingBy: 60)
        return String(format: "%02d:%05.2f", minutes, secs)
    }
}
