  Your app was suffering from a critical architectural flaw where expensive objects

  - ObservableWrapper constantly initializing/deinitializing
  - Player instance counts fluctuating (1→0→1) instead of staying stable
  - Dual state management systems causing sync issues

  The Goal: Create a State-First Architecture with:
  - Single source of truth (AddMoveUnifiedState)
  - Persistent player management (UnifiedPlayerManager)
  - Dumb views that only render, don't create state
